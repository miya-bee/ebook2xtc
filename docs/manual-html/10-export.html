10. プレビューとXTC／XTCH出力

取得したRAWは、「出力・画質」タブでXTC（2階調）やXTCH（4階調）に書き出します。書き出す前に、右ペインで仕上がりを確認できます。RAWは書き出しで上書きされないので、設定を変えて何度でも書き出せます。

既定では、1ページ目から作る一覧用のサムネイルを埋め込みます。意図した表紙が1ページ目にあることを、書き出す前に確認してください。

プレビューで確認する

右ペインの取得ページの一覧、またはプレビューの下の「◀ 前ページ」「次ページ ▶」とページ番号の欄で、表示するページを移動します。上部の欄で、プレビューの種類を選びます。

この「◀ 前ページ」「次ページ ▶」は、保存済みのページを表示するだけで、AVDのページは送りません。AVDへページを送るのは、「取得」タブの③の欄にある同じ名前のボタンです（7章）。

種類使いどころ
RAW取得した画像そのもの。ページ順や、通知が写り込んでいないかの確認
XTC 2階調プレビュー白黒2階調にしたときの文字のつぶれ・かすれの確認
XTCH 4階調プレビュー4階調にしたときの挿絵や薄い文字の確認
余白・切り出しプレビュー余白削減や出力用切り出しで、どこまで残るかの確認

出力の設定を変えると、選択中のページのプレビューがすぐに更新されます。プレビューと書き出しは、同じ処理と同じ値を使います。

形式・画質・画像処理

「形式・画質・画像処理」の枠の項目です。

項目選択肢・初期値説明
形式XTC (2階調)／XTCH (4階調)／XTCとXTCH（2形式を同時に出力）書き出す形式です。「XTCとXTCH」では、同じ処理条件でXTCとXTCHを続けて書き出します
XTC圧縮非圧縮のみ（初期値）／LZ4圧縮のみ（*_comp.xtc／*_comp.xtch）／非圧縮とLZ4圧縮を両方出力LZ4圧縮版は対応ファームウェアが必要です
画質プリセット手動設定／文字優先／バランス／挿絵優先下の「画質プリセット」を参照してください
しきい値0〜255（初期値128）明るさの境目です。上げるほど黒く（濃く）なる画素が増えます。XTCではディザがオフのときだけ使い、XTCHでは4階調に分ける境目の基準になります
余白オリジナル／余白削減 1／余白削減 2余白削減を選んでも、表紙（1ページ目）はオリジナルの余白を保ち、2ページ目から削減します。「出力用切り出し」を入力すると選べなくなります
文字太らせオフ（初期値）／オンオンにすると太さ5が選ばれます。オフでは太さのチェックボックスは操作できず、文字太らせを適用しません
太さ（複数選択可）1（最弱）〜8（最強）のチェックボックス1つ選ぶとその太さで通常出力します。2つ以上選ぶと太さごとに比較出力します。右ペインのプレビューは、選択中の最小の太さを表示します
細い線の保護オフ／弱（初期値）／標準ディザをオフにしたXTCで、欠けた横線や薄い横棒を補います。文字太らせ5以上を想定しています。XTCHとディザがオンのXTCには適用しません
出力用切り出し任意：X,Y,幅,高さ（例 0,0,960,1600）全ページ共通で、RAWの座標で切り出します。入力すると「余白」より優先されます
ディザを有効にするオン（初期値）中間の明るさを点の密度で表します。挿絵の階調が残る一方、文字の周りに点が出ることがあります
出力を反転する（黒背景・白文字）オフ（初期値）XTC／XTCHのページ画像を白黒反転して出力します。右ペインのXTC／XTCHプレビュー、埋め込みサムネイルにも反映します。RAW画像は変更しません
サムネイルを埋め込むオン（初期値）1ページ目から作る180×270の一覧用画像（XTG）を埋め込みます。LZ4圧縮版にも入ります。互換性を比べるときはオフにします。オフでもヘッダーは56バイト形式で、作業フォルダーの出力記録（session.json）にサムネイルなしと記録します。X4実機での一覧表示は未確認です
背景ノイズ抑制（白に近い画素を白固定）オン（初期値）XTCHでディザがオンのときだけ使えます。「XTCとXTCH」ではXTCHのファイルだけに適用します。明るさ245以上の画素を白に固定し、周りからのディザの誤差も遮断します

画像は出力寸法へ一度だけ縮小します。縮小方式はlanczosに固定しています（実際の本のページで比べたところ、文字の形を最も正確に残したためです。bilinearでは横線が切れ、nearestでは線が消えることがありました）。余白削減や切り出しで拡大縮小が入るときは、輪郭を軽く補正してから階調化します。

表紙（1ページ目）は、余白削減1・2でも余白を削減しません。右ペインの余白・切り出しプレビューとXTC／XTCHプレビューにも、この扱いが反映されます。手動の「出力用切り出し」を指定した場合は、その切り出しを表紙にも適用します。

⚠️ 文字太らせと背景ノイズ抑制の注意: 文字太らせを強くすると、挿絵の暗い部分や、文字の細い隙間にも影響します。背景ノイズ抑制では、薄い文字や淡い挿絵が欠けることがあります。どちらも、プレビューで本文とルビを確認してから書き出してください。

「細い線の保護」は、ディザをオフにしたXTCで、文字太らせ後に2階調化すると消える薄い横線を補います。両端が黒い短い欠けと、周囲が明るく細い横棒を対象にします。白い文字間や孤立した点は補いません。「弱」は短い欠けと一定以上の長さの横棒、「標準」はもう少し広い範囲を対象にします。ルビの隙間がつながる場合があるため、右ペインのXTCプレビューでルビの多いページも確認してください。ディザをオンにしたXTCとXTCHには適用されません。

ページごとのディザ設定

「ページごとにディザを自動判定」をオンにすると、取得したRAWごとに、写真・挿絵らしい濃淡が十分あるかを判定します。画像と判定したページはオン、文字中心や判断が難しいページはオフで出力します。ルビを含む文字が画像と誤判定されにくいよう、保守的な条件にしています。

右ペインはページの選択とプレビューに使います。ページを選んだら、「出力・画質」タブの「選択ページのディザ」で判定結果を確認し、必要なら「このページはディザ オン／オフ」に変更してください。「自動判定を使う」に戻すと自動判定に戻ります。選択ページの設定は自動判定がオンのときだけ使われ、作業フォルダーに保存されるため、作業再開後も引き継がれます。自動判定をオフにするとページ別設定欄は使えず、「ディザを有効にする」の設定が全ページに適用されます。

自動判定をオフにすると、従来どおり「ディザを有効にする」のオン・オフをすべてのページに使います。自動判定は元のRAWを対象とするため、線画や文字と画像が混在するページ、余白の切り出し後の内容では意図どおりにならないことがあります。XTC／XTCHプレビューで確認してから書き出してください。判定はページ単位であり、同じページ内の文字と絵を領域ごとに分けて処理する機能ではありません。

画質プリセット

画質プリセットは、比較を始めるための設定の組み合わせです。 アプリの「画質プリセット」横の「？」でも各設定を確認できます。どれも実機では評価していません。 選ぶと、次の値がまとめて設定されます。

プリセット余白文字太らせしきい値ディザ
文字優先（試験設定・実機未評価）余白削減 15128オフ
バランス（比較設定・実機未評価）オリジナルなし128オフ
挿絵優先（試験設定・実機未評価）オリジナルなし128オン
  • プリセットを選んだ後に個別の値を変えると、表示が「手動設定」に戻ります。
  • 書き出したときの出力記録（session.json）には、使ったプリセットのIDを記録します。
  • 実機で良い結果が得られた設定を基準にして、必要なら個別の値を調整してください。

書き出す

  1. 「書き出し」の「選択形式を書き出す」を押します。
  2. 保存先を選びます。既定の保存先は作業フォルダーで、ファイル名は「書名 - 作者」です（下の「ファイル名」）。「XTCとXTCH」ではXTCのファイル名を選び、XTCHは同じ名前で拡張子だけ変えて保存します。
  3. 「出力内容の確認」で、次の内容を確かめます。
確認する項目内容
ページ数書き出すページの数
RAW解像度取得したRAWの寸法（例：960×1600）
出力形式形式・機種・出力寸法、圧縮の有無
保存先書き出すファイルの数と一覧。「XTCとXTCH」と「非圧縮とLZ4圧縮を両方出力」を組み合わせると、最大4ファイルです
処理条件余白／切り出し、文字太らせ（比較書き出しでは選んだ太さの一覧）、しきい値、ディザ、背景ノイズ抑制、反転モード、画質プリセット
  1. 画像に通知やアカウント情報が含まれていないかも確かめ、「Yes」で書き出しを始めます。「Cancel」を押すと書き出しません。
  2. 書き出し中は進捗バーが表示されます。RAWの確認・ページの変換・索引の作成・ページデータの書き込み・LZ4圧縮の段階ごとに、「ページを変換中: 12/120ページ」のように処理済みのページ数と総ページ数を示します。非圧縮・圧縮のどちらでも、分母は総ページ数です。段階が変わると、数字は0から数え直します。
  3. やめるときは「変換をキャンセル」を押します。途中まで書き出したファイルは完成扱いにしません。「XTCとXTCH」でXTCHの途中にキャンセルまたは失敗した場合は、書き終えたXTCのファイルも削除し、何も出力しなかった状態に戻します。進捗の段階名には「XTC:」「XTCH:」が付きます。
  4. 終わると「出力完了」が開き、出力ファイルの場所が表示されます。

出力ファイルの横に処理記録（.manifest.json）は作りません。どのファイルをどの条件で作ったかは、作業フォルダーの session.json の出力記録に、ファイルごとに残ります（形式、LZ4圧縮の有無、文字太らせ、余白、縮小方式、しきい値、ディザ、背景ノイズ抑制、反転モード、画質プリセット、サムネイルの有無）。以前の版で作られた処理記録は、アプリからは削除しません。

📏 選んだ機種の原寸または2倍以外の寸法のRAWが含まれていると、「対応外のRAW寸法です」と表示して書き出しません。⓪出力対象が、取得したときの機種と同じか確かめてください。

文字太らせを比べる

文字太らせは、実機での読みやすさに大きく影響します。「文字太らせ」をオンにし、「太さ（複数選択可）」で太さを2つ以上選ぶと、1回の操作で太さごとに書き出せます。

  1. 「出力・画質」タブの「文字太らせ」をオンにし、「太さ（複数選択可）」で比べたい太さにチェックを付けます（例：5、6、7）。書き出しボタンが「太さ3種類で書き出す」に変わります。
  2. ボタンを押し、保存先を選びます。選ぶのは太さを付ける前の名前（例：草枕 - 夏目漱石.xtc）で、実際のファイル名には _W5 のように太さが付きます。
  3. 「出力内容の確認」で、作られるファイルの一覧を確かめてから「Yes」を押します。
  4. 書き出し中の進捗には「太らせ5 XTC: ページを変換中: 12/120ページ」のように太さが表示されます。
  5. 途中でキャンセルまたは失敗した場合は、書き終えた太さのファイルもすべて削除し、何も書き出さなかった状態に戻します。
  • 太さを1つ選んだ場合は通常のファイル名で、その太さを適用します。複数選んだ場合は各ファイル名に _W5 のような太さが付きます。太さ以外の値（余白・しきい値・ディザ）は、今の設定のまま使います。
  • 文字太らせをオフにすると太さのチェックは外れ、選択もできなくなります。
  • 書き出し時間は、選んだ数にほぼ比例して増えます（3種類で約3倍）。フォントテストで止めた10ページ程度の作業フォルダーで比べると、短い時間で済みます（7章）。
  • 右ペインのプレビューは、選択中の最小の太さで表示します。複数選んだ場合は、各太さの出力を実機で比較してください。
  • チェックの状態は、次回の起動にも引き継がれます。

ファイル名

「書名 - 作者」を共通のベース名にします。

出力ファイル名の例
XTC草枕 - 夏目漱石.xtc
XTCH草枕 - 夏目漱石.xtch
LZ4圧縮のみ草枕 - 夏目漱石_comp.xtc（XTCHなら _comp.xtch）
両方草枕 - 夏目漱石.xtc と 草枕 - 夏目漱石_comp.xtc
XTCとXTCH草枕 - 夏目漱石.xtc と 草枕 - 夏目漱石.xtch
XTCとXTCH＋両方草枕 - 夏目漱石.xtc、草枕 - 夏目漱石_comp.xtc、草枕 - 夏目漱石.xtch、草枕 - 夏目漱石_comp.xtch（4ファイル）
文字太らせの比較（5・6・7）草枕 - 夏目漱石_W5.xtc、草枕 - 夏目漱石_W6.xtc、草枕 - 夏目漱石_W7.xtc
比較＋LZ4圧縮版草枕 - 夏目漱石_W5_comp.xtc のように、太さの後に _comp が付きます
  • 書名だけ、作者だけの場合は、入力したほうだけを使います。どちらも空なら output になります。
  • \ / : * ? " < > | などファイル名に使えない文字は _ に置き換え、長さは120文字までにします。
  • 同じ名前の出力がすでにある場合は、上書きせずに 草枕 - 夏目漱石(1).xtc、(2) …のように番号を付けます。「両方」や「XTCとXTCH」では、どれか1つでもあれば、すべてに同じ番号を付けます。文字太らせの比較では、番号は太さの後に付きます（草枕 - 夏目漱石_W5(1).xtc）。
  • XTC／XTCHコンテナのヘッダーは、LZ4圧縮版も含めて56バイト形式です。ページ索引は56バイト目から始まり、旧48バイト形式は完成品として保存しません。サムネイルをオフにしてもヘッダーは56バイトです。
  • Studioと同じ方式で、圧縮効果のある本文ページの画像データだけをLZ4圧縮します。圧縮ページのヘッダーには圧縮フラグ1と圧縮後の長さを記録し、索引とサムネイル位置を更新します。サムネイルは圧縮しません。圧縮できるページが1枚もない場合、圧縮版は作成しません。「両方」では非圧縮版だけを保存し、完了時のステータスに「圧縮効果のあるページがないため、LZ4圧縮版は作成しませんでした」と表示します。
  • 旧版の.xtczは異なる形式で、拡張子を.xtcや.xtchに変えるだけでは読めません。保存済みのRAWから書き出し直してください。

📁 旧版のファイルは自動で置き換わりません: 48バイト形式のXTC／XTCHが残っている場合は、現行版で作業フォルダーのRAW画像から書き出し直し、「出力完了」に示された新しいファイルを実機へコピーしてください。同名ファイルがあれば (1) などの番号が付くため、古いファイルを選ばないよう注意してください。RAWを削除済みの場合は、書き出し直しの前に元画像の有無を確認してください。

📟 LZ4圧縮版は対応ファームウェアが必要です: 端末とファームウェアごとの互換性を確認してください。

実機で確認する

選択した機種で開き、本文・漢字・ルビ・余白・濃さ・ページ順を確認します。設定を比べるときは、処理条件を変えて書き出したファイルを実機で見比べてください。アプリは画質を自動では判定しません。

🧪 X3で開けることは、まだ実機で確認していません。X3で使う場合は、短い出力で開けるかを先に確かめてください。

書き出しに成功したら、中間PNGを残すか消すかを決めます（次章）。

キャプチャ中は書き出しを開始できず、書き出し中は追加のキャプチャを開始できません。RAWの消去を案内する前に、最後に書き出したページと現在のRAWページが一致するかを確認します。書き出し後にページを追加・変更した場合、RAWは保持されます。
