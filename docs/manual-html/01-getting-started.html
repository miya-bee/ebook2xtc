1. はじめに・画面の見方

🧪 このマニュアルは v0.4.0 を対象にしています。フォルダー版はインストーラーではありません。

ebook2xtcでできること

ebook2xtcは、Androidエミュレーター（AVD）に表示した電子書籍リーダーアプリの読書画面を1ページずつ取得してRAW PNGとして保存し、XTEINK X4またはX3向けのXTC／XTCH（必要ならページ単位LZ4圧縮版）へ書き出すWindowsアプリです。

出力対象出力寸法原寸で取得2倍で取得
XTEINK X4480×800480×800960×1600
XTEINK X3528×792528×7921056×1584
  • 画像は、ADBでAndroidの画面バッファを直接受け取って取得します（ADB直接取得）。AVDのウィンドウの位置や大きさ、Windowsの表示倍率には左右されません（5章）。
  • 2倍で取得したRAWは、書き出すときに出力寸法へ高品質に縮小します。
  • 保護された画面は黒画像などとして返る場合があります。ebook2xtcは保護を回避せず、中央がほぼ全黒の画像は保存せずに止まります（7章）。

画面の構成

画面は左右2つに分かれています。境目をドラッグすると左右の幅を変えられます。ウィンドウの配置は、次回の起動に引き継がれます。

部分役割
左：設定エリア「取得」「出力・画質」「その他」の3つのタブ。AVDの起動、キャプチャの手順、出力の設定を行います
左下：ステータス直前の操作の結果や、RAWを保存しなかった理由を表示します（起動直後は「準備完了」）。困ったときは、まずここを読んでください
右：取得ページ保存したページの一覧。000001 page_000001.png のように、ページ番号とファイル名が並びます。重複や交互ループの候補には ⚠ が付きます
右：プレビュー一覧で選んだページの表示。上部でプレビューの種類を選び、プレビューの下の「◀ 前ページ」「次ページ ▶」とページ番号の欄で、表示するページを移動します。これらは保存済みのページを表示するだけで、AVDのページは送りません

AVDの起動や寸法の確認の結果は、「取得」タブの「事前準備」の枠内にも表示されます。

左の設定エリアでは、マウスのホイールは設定エリアのスクロールだけに使います。ポインターが選択欄や数値欄、タブの上にあっても、ホイールで設定やタブは変わりません。設定を変えるときは、クリックして選ぶか、数値を入力してください。

プレビューの種類は次の5つです。

種類表示する内容
RAW保存したPNGそのもの
XTC 2階調プレビュー現在の出力設定でXTCにしたときの見え方
XTCH 4階調プレビュー現在の出力設定でXTCHにしたときの見え方
余白・切り出しプレビュー余白削減や出力用切り出しの範囲の確認。「余白」を変えると自動でこの表示になります
AVDライブ（密度確認）DPI調整の直後に取得した、AVDの現在の画面（9章）

タブごとの主な項目は、目次ページ の「画面の3つのタブ」にまとめています。

起動する（Python開発版）

Windows 11でプロジェクトのフォルダーを開き、PowerShellから開発環境を作ります。Pythonは3.10を使います。

py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[desktop]"
.\.venv\Scripts\python.exe -m s4capture.gui

2回目以降は最後の起動コマンドだけを実行します。AVDを使うには、Android SDKの platform-tools\adb.exe と emulator\emulator.exe が必要です（2章）。

起動する（試験用フォルダー版）

配布フォルダー内の start_ebook2xtc.bat をダブルクリックします。バッチファイルは、同じフォルダーの ebook2xtc.exe を起動します。

  • start_ebook2xtc.bat、ebook2xtc.exe、_internal、manual、環境JSONは同じ配布フォルダーに置いたままにします。
  • SmartScreenが警告する場合、バッチからの起動でも警告は解除されません。配布元とファイルを確認し、実行を許可できる場合にだけWindowsの案内に従ってください。管理対象のPCで禁止されている場合は管理者に確認してください。
  • 設定は同じフォルダーの ebook2xtc.ini に保存されるため、フォルダーに書き込み権限が必要です（13章）。
  • この版にも、Android SDK、AVD、リーダーアプリ、X4／X3実機は含まれません。
  • 作り直す方法は、プロジェクト内の packaging/README.md を参照してください。

起動したときに表示されるもの

  • 起動直後は「Android環境を確認しています…」と表示され、AVDの一覧と仮想化の確認を裏で行います。確認には十数秒かかることがあり、その間はアプリを閉じられません。
  • AVDの一覧は読み込みますが、AVDを自動では起動しません。起動中のAVDがあっても、自動で設定し直すことはありません。
  • フォルダー版では、同梱の環境JSONとSDKを確認します。「取得」タブ上部の「Android環境の準備」からAndroid Studioの入手、導入手順、標準AVDの設定へ進めます。準備完了後も「環境準備済み」の短い表示が残り、「導入・再設定を開く」で再確認できます（13章）。
  • 前に使った作業フォルダーにRAW PNGが残っていると、「残っている中間PNGの確認」が開きます。残すか消すかを、作業フォルダーごとに選べます（11章）。迷ったら「保持して続行」を押してください。

このマニュアルを開く

「その他」タブの「マニュアルを開く」を押すと、このマニュアルが既定のブラウザーで開きます。インターネット接続は不要です。「マニュアルが見つかりません」と出た場合は、ebook2xtc.exe と同じフォルダーに manual フォルダーがあるか確認してください。

最初に確かめる項目

「取得」タブの「事前準備：取得方式と解像度を選んでからAVDを起動」で、AVDを起動する前に次の項目を確かめます。

  1. ⓪「出力対象」：XTEINK X4 (480×800) または XTEINK X3 (528×792)
  2. ①「取得方式」：ADB直接取得（選択肢はこの1つだけで、表示のみです）
  3. ②「キャプチャ解像度」：原寸 または 高画質 2倍（初期値は高画質 2倍）

②に表示される寸法は、⓪で選んだ機種に合わせて変わります。選び終えたら、③からAVDを起動します（5章）。

AVDをまだ作っていない場合は、次章から順に準備します。
