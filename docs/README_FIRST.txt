ebook2xtc　はじめにお読みください
================================

ebook2xtcは、Androidエミュレーターに表示した読書画面を取得し、
XTEINK X4／X3向けのXTC・XTCHファイル（LZ4圧縮版を含む）を作るWindowsアプリです。

【1．配布フォルダーを置く】

ZIPを展開し、ebook2xtcフォルダーをそのまま、書き込み可能なローカルディスクへ置いてください。
OneDriveと関連のない場所（例：C:\ebook2xtc）を推奨します。
ebook2xtc.exeだけを取り出さず、start_ebook2xtc.bat、_internal、manual、
ebook2xtc-S4Capture_API35_Play-environment.jsonを同じフォルダーに残してください。
このアプリはインストーラーを使いません。start_ebook2xtc.batをダブルクリックして起動します。
バッチファイルは、同じフォルダーのebook2xtc.exeを起動します。

WindowsのSmartScreenが警告する場合、バッチから起動しても警告は解除されません。
配布元とファイルを確認し、実行を許可できる場合にだけWindowsの案内に従ってください。
組織のPCで実行が禁止されている場合は管理者に確認してください。

【2．Androidの準備（初回のみ）】

この配布フォルダーには、Android Studio、Android SDK、電子書籍リーダーアプリは含まれません。
Android Studioをインストールし、SDK Managerで次のものを用意してください。

・Android SDK Build-Tools（Android Studio標準。ebook2xtcは直接使用しません）
・Android Emulator
・Android SDK Platform-Tools
・Android SDK Command-line Tools (latest)（AVD作成に必須）
・Android 15／API 35のGoogle Play対応x86_64 System Image

SDK Toolsタブでは、上のBuild-Tools、Emulator、Platform-Tools、Command-line Toolsの
計4項目にチェックまたは青い横棒が付き、導入済みであることを確認してください。
特にCommand-line Toolsはチェックを付けただけでは不十分です。
「Apply」を押し、「Installed」になるまで待ってください。

初回はSDK Managerの「SDK Platforms」タブでAndroid 15（API 35）を開き、
Android SDK Platform 35とGoogle Play対応x86_64 System Imageにチェックを入れ、
「Apply」でインストールしてください。導入後、両方がInstalledと表示されることを確認します。
16／17では代用できません。既にほかの版が入っていても、アンインストールは不要です。

Android Emulatorを入れたら、早めにアプリの「準備を再確認」を押してください。
仮想化の警告がなければ、このためのPC再起動は不要です。
警告が出た場合は、後の手順でWindows PC本体の再起動が必要になるかを確認します。
了承する場合は「OK」を押してください。「キャンセル」ではセットアップに進みません。
OKの後は、環境JSONの読み込みとAVD作成を先に進められます。
AVDを初めて起動する前に「Windowsの機能を開く」で
「Windows ハイパーバイザー プラットフォーム」を有効にしてください。
この設定を変更した場合だけ、Windows PC本体を一度再起動します。
ebook2xtcだけの再起動では反映されません。

同梱JSONに必要なSystem Imageが見つからない場合は、アプリのエラーに表示されたSDKの場所と
Android Studioの「Android SDK Location」を比較してください。複数のSDKがあるPCでは、
アプリがAndroid 15／Google Play／x86_64のイメージを持つSDKを優先して探します。
自動で認識しない場合は、取得タブ最上部の「SDK保存先を指定（認識しない場合）」で
Android Studioに表示されたSDKフォルダーを選んでください。指定先はiniに保存されます。

詳しい画面操作は、manual\index.htmlの2章と13章を参照してください。
アプリの「取得」タブ最上部からAndroid Studioの公式ダウンロードページと導入手順を開けます。
準備完了後は「導入・再設定を開く」で、これらのボタンを再表示できます（開いている間は「導入・再設定を閉じる」に変わり、押すと折りたたみます）。
導入中に「準備を再確認」を押した場合は、準備済みでも操作欄は閉じません。
AVD作成に必要なJavaは、通常Android Studio付属のものをアプリが自動で使用します。

【3．同梱の標準環境を設定する】

初回起動時、アプリは同じフォルダーの環境JSONを自動で確認します。
「取得」タブ上部に「Android環境の準備」が出たら、
「標準環境をセットアップ」を押してください。JSONを手で選ぶ必要はありません。

必要なSystem Imageが未導入と表示された場合は、手順2で導入してから
「準備を再確認」を押してください。作成中はアプリを終了せずにお待ちください。
同じ設定のAVDがすでにある場合は再利用します。
同名でも設定が異なる場合は、既存AVDを残して別名で作るかを確認します。

完了後、「取得」タブの⓪出力対象・①取得方式・②キャプチャ解像度を確認し、
③でAVDの「起動」を押してください。AVDは自動では起動しません。

【4．AVDとリーダーアプリの初期設定】

新しいAVDの初回起動後、Androidの初期設定を完了してください。
Google Playからお使いの電子書籍リーダーアプリをインストールし、ご自身のアカウントでログインします。
ebook2xtcの取得タブにある「リーダーアプリ」欄の「AVDから選ぶ」で、そのアプリを選びます。
必要に応じてAndroidとリーダーアプリを日本語表示にし、PCキーボード入力と
画面が途中でスリープしない設定を確認してください。

同梱JSONにリーダーアプリ本体、ログイン情報、書籍データは含まれません。
JSONに記録されたリーダーアプリのバージョンは、作成元の参考情報です。
詳しくはマニュアルの3章、4章、13章をご覧ください。

【5．使い始める前に】

新しい作業フォルダーも、OneDriveと関連のないローカルディスクに作成してください。
キャプチャ中の画像は作業フォルダーに保存されます。取得・変換が終わるまで
作業フォルダーを移動・削除しないでください。
取得できない画面や保護された画面では処理が停止します。
利用する書籍や画面について、必要な権利・許可を確認してください。

XTCとXTCHは、LZ4圧縮版も含めて56バイトのヘッダーで出力します。
圧縮版は本文ページだけを圧縮し、*_comp.xtc／*_comp.xtchという名前で保存します。
旧版の.xtczは異なる形式なので、拡張子を変えるだけでは読めません。
旧版で作った48バイト形式のファイルは自動修復されません。
元のRAW画像が残っている場合は、この版で書き出し直してください。
同名の旧ファイルが残っていると、新しいファイル名には(1)などが付きます。

【マニュアルと設定ファイル】

操作マニュアルは「その他」タブの「マニュアルを開く」から読めます。
ブラウザーでmanual\index.htmlを直接開くこともできます。閲覧にネット接続は不要です。

アプリの設定は、ebook2xtc.exeと同じフォルダーのebook2xtc.iniへ保存されます。
このフォルダーに書き込み権限が必要です。INIにGoogle／リーダーアプリの
パスワードや書籍データは保存されません。

【新しい版に更新するとき】

新しい版のZIPは、古い版とは別のフォルダーに展開してください。
古いebook2xtcフォルダーへの上書き展開はしないでください（古いファイルが残り、
起動に失敗することがあります）。

新しい版を最初に起動すると「設定の引き継ぎ」が表示されます。
「引き継ぐ…」を押し、古い版のフォルダーにあるebook2xtc.iniを選ぶと、
設定をそのまま使えます。動作を確かめてから、古い版のフォルダーを削除してください。
詳しくはマニュアル13章「新しい版に更新するとき」をご覧ください。
