# 11. 書籍情報・目次と合本の分割
{: .no_toc}

「書籍情報・目次」の枠では、XTC／XTCHに書き込む書籍情報と目次を設定します。日本語XTC GUI Studio v5と同じ形式で書き込むので、端末の書籍一覧や、目次から章へ移動する機能で使われます（使われ方はファームウェアによって異なります）。

## 「書籍情報・目次」の枠の項目

| 項目 | 説明 |
|---|---|
| 書籍情報と目次をXTC／XTCHに書き込む | オン（初期値）にすると、取得タブ⑧の書名・作者・出版社と、開始ページを設定した章を書き込みます。オフにすると、これまでどおり書籍情報なしで書き出します。この設定は作業フォルダーごとに保存し、次にその作業フォルダーを開いたときに戻します（まだ保存していない作業フォルダーでは、直前の設定のままです） |
| （要約） | 書き込む書名・作者・出版社と、章の数を表示します |
| 目次と章の開始ページ… | 章名と開始ページを確認・修正する画面を開きます。保存済みのページがあるとき（書き出し中を除く）に押せます |
| 巻ごとに分けて出力 | 合本版を巻ごとのファイルに分けて出力します。目次に巻の行があるときだけ選べます。初期値はオフで、作業フォルダーごとに覚えます（下の「合本版を巻ごとに分けて出力する」） |

## 章の開始ページを照合する

「目次と章の開始ページ…」の画面は、左に目次の章名と開始ページの一覧、右に保存済みのページ（RAW）のプレビューがあります。章名と開始ページは一覧で直接修正できます。

一覧の列：

| 列 | 説明 |
|---|---|
| 左端 | 行の番号です。合本の巻の行は「1巻」「2巻」と表示し、章名を太字にします |
| 自動 | チェックした行を「開始ページを自動で探す」（と、巻末で止まったときの自動の検索）の対象にします。読み取った直後の章はチェック付き、「行を追加」で足した章はチェックなしです。開始ページを手で設定するとチェックが外れます |
| 章名 | ダブルクリックで修正できます。章名を空にした行は、「OK」で保存するときに一覧から除きます |
| 開始ページ | 保存済みのページの番号です。0（「未設定」）の章は書き込みません。数字を変えると、右のプレビューもそのページに移ります。マウスのホイールで数字が変わるのは、欄をクリックして入力中のときだけです（一覧をスクロールしても変わりません） |
| 状態 | 「照合済み」（自動で見つかった）、「見つからず」（自動で見つからなかった）、「手動」（手で入力した、またはプレビューから設定した）を表示します |
| 表紙 | 合本の巻の行だけに、その巻のファイルの1ページ目にする表紙を表示します。「4（自動）」（自動で見つけたカラーの表紙）、「6（手動）」（手で決めた表紙）、「表紙なし」のどれかです（下の「合本版を巻ごとに分けて出力する」） |

行を右クリックすると、次のメニューが出ます。
- 「この行を巻にする」／「巻にしない（章の行に戻す）」：合本の巻の行にするかどうかを切り替えます。書名に巻番号が付いていない巻（「第一部」など）を巻にするときに使います。「巻にしない」を選んだ行は、作業フォルダーに記録し、名前に番号が付いていても（「特別講義1」「特別講義2」のような章）、「巻の始まりを探す」や章探しで巻として扱いません。
- 「巻かどうかを自動で決める（「巻にしない」をやめる）」：「巻にしない」を選んだ行だけに出ます。初めの状態（名前から巻かどうかを決める）に戻します。
- 巻の行では、さらに「表示中のページ（〇ページ）を、この巻の表紙にする」「表紙を使わない（巻の開始ページから始める）」「表紙を自動で見つける（開始ページの前のカラーのページ）」を選べます。

右のプレビューでは、ページを見ながら開始ページを決められます。

- 一覧で行を選ぶと、その章の開始ページを表示します。開始ページが「未設定」の章では、表示中のページのままにします（前の章の開始ページを入力して次の章へ移ったときも、ページは進みません）。ただし、表示中のページが前の章の開始ページより前のときは、前の章の開始ページの次のページへ移ります。
- 「◀ 前」「次 ▶」で1ページ、「≪ 10」「10 ≫」で10ページずつ移動します。ページ番号の欄に直接入力して移動することもできます。
- 「このページを選択中の行の開始ページにする」で、一覧で選択中の行（章や巻）の開始ページを、表示中のページにします（状態は「手動」）。設定すると、一覧の選択が次の行へ移るので、続けて次の章の開始ページを探せます（最後の行では選択はそのままです）。次の章の開始ページが未設定なら、プレビューは表示中のページのままです。
- 「このページを選択中の巻の表紙にする」：合本版で、一覧で選択中の巻のファイルの1ページ目を、表示中のページにします。巻の行を選んでいるときだけ押せます。その巻の開始ページ（扉）より前で、前の巻の開始ページより後ろのページだけを指定できます。それ以外のページでは、指定できない理由を表示します。表紙を使わない・自動に戻すは、巻の行を右クリックして選びます。選ぶと、その場で作業フォルダーに保存します。
- プレビューの下に、表示中のページから始まる章を表示します。
- 中間PNGを消去した作業フォルダーでは、プレビューは表示されません。

一覧の下のボタンと、画面を閉じるボタン：

- 「目次をKindleから読み込み直す…」（楽天Koboでは「目次を楽天Koboから読み込み直す…」）：リーダーアプリの目次から章名を読み取り、一覧を置き換えます（取得タブ⑧の読み取りと同じです）。一覧に章があるときは、置き換えてよいか確認します。入力済みの開始ページと巻の設定も消えます。章名を1つも読み取れなかったときは、一覧をそのまま残します。読み取った書名・作者は「OK」を押したときに⑧へ入ります。取得中は押せません。
- 「開始ページを自動で探す」：「自動」欄にチェックした行の開始ページを、次の順に探します。照合できた章は「照合済み」、見つからなかった章は「見つからず」と表示します。見つからなかった章は、前に入っていた開始ページも「未設定」に戻ります（古いページのまま書き出されないようにするためです）。右のプレビューで探して開始ページを設定します。
  1. 保存済みのページ（RAW）の文字をWindowsの文字認識（OCR）で読み取り、目次の章名が書かれたページを探します。リーダーアプリもAVDも使いません。100ページあたり4秒ほどかかります（長い本は、いくつかのページを同時に読み取ります。読み取った文字は作業フォルダーの `chapter_text.json` に残し、2回目からは数秒で終わります）。縦書きも横書きも読めます。目次の順に並ぶように選び、本の中の目次のページ（章名がたくさん並ぶページ）は開始ページにしません。「表紙」「目次」「奥付」は、表紙は1ページ目、目次は本の中の目次のページ、奥付は巻末の発行者や発行日のあるページ、というように決めます。
  2. 文字から見つからなかった章（見出しが画像になっている章など）は、リーダーアプリがKindleか楽天Koboなら、その目次から1つずつ開き、表示されたページを保存済みのRAWと比べて探します。Kindleでは1章あたり8秒ほど、楽天Koboは目次をいつも先頭から開くため、目次の前のほうの章で10〜15秒、後ろのほうで30〜35秒ほどかかります。AVDを起動していないときや、ほかのリーダーアプリのときは、この手順は行いません。
     - 使うリーダーアプリは、その作業フォルダーの本を取得したアプリです（⑥で開いたアプリを作業フォルダーに記録します。⑥を使わずに「現在のページを保存」などで取得したときは、ページを保存した後に裏で確かめ、画面の前に出ていたのが取得タブで選んでいるリーダーアプリなら、それを記録します。確かめられなかったときは、次にページを保存したときにまた確かめます）。取得タブで別のリーダーアプリを選んでいても変わりません。
     - どのリーダーアプリで取得したかの記録がない作業フォルダー（前の版で作ったものなど）では、1.で見つからない章が残ったときだけ、「〇章がページの文字から見つかりませんでした。」と一緒に「リーダーアプリの確認」が表示されます。1.で全部見つかったときは表示されません。「この本は〇〇で取得しましたか？」に「はい」を押すと、そのリーダーアプリで残りの章を探し、作業フォルダーに記録します（次からは聞きません）。「いいえ」を押すと、リーダーアプリは使わず、1.の結果だけにします。
     - 書名・目次の読み取りは必ずリーダーアプリを使うので、記録がない作業フォルダーでは、読み取る前に同じ確認が出ます。「いいえ」を押すと、読み取りません。
     - リーダーアプリを使う前に、Androidの画面に表示中のアプリを確かめます。その間は「リーダーアプリの確認」の進み具合の画面が出ます（長くても6秒ほどで、「中止」で止められます。止めた場合は、確かめられなかったものとして扱います）。
     - Androidの画面に表示中のアプリを確かめられないとき（AVDが応答しない、画面の切り替え中など）は、何回か確かめ直します。それでも分からなければ、リーダーアプリは使わず、ページの文字だけで探します。ボタンの下に「Androidの画面に表示中のアプリを確認できなかったため…」と表示します。
     - そのリーダーアプリがAndroidの画面の前に出ていないとき（次の本のためにほかのリーダーアプリを開いた後など）は、この手順を行わず、1.の結果だけにします。ボタンの下に「楽天Koboが前に出ていないため、楽天Koboの目次では探しませんでした」のように理由を表示します。残りの章も探すときは、⑥でその本のリーダーアプリを開き、本を表示してから、もう一度「開始ページを自動で探す」を押します。
     - 表示されたページとよく似たページ（白紙のページや、同じ図柄の部扉など）が本の離れた所にもあって、どれか決められないときは、その章を「見つからず」にします。ボタンの下に、決められなかった章の数を表示します。右のプレビューで探して設定してください。
  - 日本語の文字認識が入っていないWindowsでは、1.を行わず、2.だけで探します（Kindle・楽天Koboのときだけ）。日本語の文字認識は、Windowsの設定の「時刻と言語」→「言語と地域」で日本語を追加すると使えるようになります（日本語版のWindowsには最初から入っています）。
- 照合し終えた章は、見つかったかどうかにかかわらず「自動」欄のチェックが外れます。開始ページを手で入力した章や「このページを選択中の行の開始ページにする」で設定した章も、チェックが外れます。このため、あとで照合しても手で設定した開始ページは上書きされません。照合し直したいときは、チェックを付け直します。照合の結果は、その場で作業フォルダーに保存します（画面を「キャンセル」で閉じても残ります）。探し終えると、ボタンの下に「開始ページを探しました: 見つかった 45章（22秒）」のように、結果とかかった時間を表示します。かかった時間は、作業フォルダーの `session.json` の目次の記録（`toc` の `last_search`）にも残ります。
- 照合を途中で「中止」した場合や、途中で失敗した場合も、それまでに照合した章の結果は残ります。残りの章はチェックが付いたままなので、もう一度「開始ページを自動で探す」を押すと続きから照合します。画面を閉じたり、アプリを終了したりした後でも同じです。見つからなかった章を照合し直すときは、その章にチェックを付け直します。
- 取得タブの「取得の終わりに、章の開始ページを探す」がオン（初期値）のときは、連続取得が巻末で止まった直後に、同じ方法で自動で探します。④・⑤で別の作業フォルダーに移るときに、チェックの付いた章が残っていれば探すかどうかを尋ねます（[7章](07-capture.md#巻末で止まったときの章の開始ページ)）。
- 楽天Koboの目次から探すときは、章へ移動した後に残るツールバーを消してから、ページを比べます。
- 「行を追加」：一覧で選択中の行のすぐ下（未選択なら末尾）に「新しい章」を追加し、章名の入力を始めます。
- 「行を削除」：一覧で選択中の行を削除します。Shift／Ctrlを押しながら選ぶと、複数行をまとめて削除できます。
- 開始ページを手で入力したときや「このページを選択中の行の開始ページにする」を押したときは、その時点の一覧（章名の修正を含む）をすぐ作業フォルダーに保存します。照合したときも同じです。
- 「OK」：一覧を作業フォルダーに保存して閉じます。開始ページが「未設定」の章は書き込みません。
- 「キャンセル」：保存せずに閉じます。ただし、開始ページの入力・設定や照合のときに保存した内容は残ります。それより後の変更（章名の修正、行の追加・削除など）だけが取り消されます。

リーダーアプリの目次から探すとき（上の2.）の注意：
- 取得したときと同じ文字サイズ・余白などの表示設定のまま行ってください。表示設定を変えると、ページの区切りが変わり、照合できません。取得が終わった直後に行うのが確実です。文字から探す1.は、表示設定に関係なく使えます。
- リーダーアプリで探したあと、リーダーアプリの表示位置は最後に照合した章に移ります。照合を中止した場合や失敗した場合も、途中の章に移っていることがあります。どの場合も、照合の最後にリーダーアプリの目次とツールバーを閉じ、ページだけの表示に戻します。取得を再開するときは「再開位置を確認」で表示位置を確かめるので、移った先のページがそのまま続きとして保存されることはありません。再開する前に、リーダーアプリで最後に保存したページまで戻してください（[13章](13-resume.md)）。
- 中間PNGを消去した作業フォルダーでは照合できません（章名と開始ページの修正はできます）。

書き込みのきまり：
- 同じページから始まる章が複数ある場合（「第4章」と「4-1」が同じページにあるなど）は、一覧で先にある1件だけを書き込みます。Studioと同じ扱いです。
- 各章は、次の章の前のページまでとします。最後の章は最終ページまでです。
- 書名は128バイト（日本語で約42文字）、作者は64バイト（約21文字）、出版社は32バイト（約10文字）、章名は80バイト（約26文字）までで、それより長い部分は切り捨てます。
- 1ページ目を表紙として記録します。
- LZ4圧縮版、XTCH v2（Comic）にも同じ内容を書き込みます。

## 合本版を巻ごとに分けて出力する

合本版（何巻かを1冊にまとめた電子書籍）は、巻ごとに別のファイルとして出力できます。取得は今までどおり合本を1つの作業フォルダーで最初から最後まで行い、目次の画面で巻の区切りを決めてから書き出します。

### 「合本を巻ごとに分ける」の枠

「目次と章の開始ページ…」の画面で、一覧に書名と巻番号でできた名前の行（「宇宙軍士官学校─攻勢偵察部隊─１」「…２」のような行）が2つ以上あるとき、または巻の行があるとき、一覧の上に「合本を巻ごとに分ける（5巻）」の枠が出ます。枠には次の3つの手順が並び、上から順にボタンを押していけば巻分けができます。

| 手順 | ボタン | すること |
|---|---|---|
| 1. 各巻の始まりを決める | 「巻の始まりを探す」 | 巻番号の付いた行を巻の行にし、各巻の扉（巻番号のあるページ）を開始ページとして探します。扉の前にあるカラーの表紙も見つけます |
| 2. 各巻の章を読み込む | 「章を読み込む」 | 各巻の中の目次ページから章名を読み取って巻の行の下に並べ、続けて章の開始ページを探します |
| 3. 確かめて保存する | （「OK」） | 内容を確かめて「OK」を押すと、「書籍情報・目次」の「巻ごとに分けて出力」がオンになります |

- 手順の左の印は、「✓」が済んだ手順、「▶」が次にする手順、「・」がまだの手順です。次にする手順の名前とボタンは太字になります。
- 済んだ手順のボタンは「やり直す」に変わります。
- 手順の下の「次にすること：」に、いまの一覧の状態から次に行うことを、具体的なボタンの名前と一緒に表示します。
- 名前に番号が付いていて巻のように見えるのに巻になっていない行（「特別講義1」「特別講義2」のような章）があるときは、「次にすること：」で、巻にするか（「巻の始まりを探す」）、章のままにするか（その行を右クリックして「巻にしない」）を選ぶよう案内します。巻にした行の始まりがそろっていれば、決めないまま「章を読み込む」へ進むこともできます。
- その下に、巻ごとのページの範囲（書き出す巻のファイルと同じ範囲。カラー表紙があれば表紙から、次の巻のファイルの最初のページの前まで）、ページ数、章の数、開始ページが未設定の章の数を表示します。カラー表紙があるときは「4〜838ページ（835ページ、4ページはカラー表紙、扉は6ページ）」のように、表紙と扉のページも表示します。巻の範囲の外のページを開始ページにした章があるときは「⚠ 巻の範囲の外のページの章」、巻の始まりが重なっているときはその巻とページを「⚠」の行で示します。
- 章を書き込まず、巻ごとに分けるだけなら、手順1の後に「OK」を押して書き出せます。

### 1. 各巻の始まりを決める

1. 取得を終えた作業フォルダーで、「書籍情報・目次」の「目次と章の開始ページ…」を押します。
2. 一覧に目次がなければ、「目次を楽天Koboから読み込み直す…」（Kindleでは「目次をKindleから読み込み直す…」）を押します。楽天Koboの合本では、目次は「表紙」「目次」と各巻の名前だけになることがほとんどです。
3. 枠の「巻の始まりを探す」を押します。
   - 巻番号の付いた名前の行を、まとめて巻の行にします（左端が「1巻」「2巻」になり、太字になります）。「表紙」「目次」など合本そのものの行は巻にしません。
   - 各巻の開始ページを、その巻の扉（巻の書名と巻番号が書かれたページ）として探します。ページの文字から、その巻の番号（「2」「第2巻」など）が書かれた最初のページを探し、文字で決まらなかった巻は楽天Kobo（またはKindle）の目次からその巻を開いて、表示されたページを保存済みのページと比べます。上の巻と同じか前のページ（下の巻と同じか後ろのページ）になったときは採らず、「見つからず」にします。
   - 扉の前4ページまでにあるカラーのページを、その巻の表紙として見つけ、「表紙」の列に表示します。
4. 始まりが「見つからず」の巻は、右のプレビューでその巻の扉を表示し、一覧でその巻の行を選んで「このページを選択中の行の開始ページにする」を押します。扉は、巻の目次のページのすぐ前にあることがほとんどです。
5. 書名に巻番号が付いていない巻（「第一部」「上巻」など）は、その行を右クリックして「この行を巻にする」を選び、開始ページを設定します。
   - 最後の巻の後ろにある「奥付」などの行は、最後の巻の章として扱われます。巻ごとのファイルに入れたくないときは、開始ページを「未設定」のままにします。
6. 自動で見つけた表紙が違うとき（広告や口絵のカラーページなど）や、表紙が扉から離れているときは、右のプレビューで表紙を表示し、巻の行を選んで「このページを選択中の巻の表紙にする」を押します。表紙を使わないときは、巻の行を右クリックして「表紙を使わない」を選びます。
7. 一度決めた後に全部探し直すときは、「やり直す」を押します。

### 2. 各巻の章を読み込む

各巻の中の章は楽天Koboの目次に出ないので、各巻の中にある目次のページ（保存済みのページ）の文字をWindowsの文字認識で読み取ります。

1. 枠の「章を読み込む」を押します。手順1が済むと押せるようになります。
   - 各巻の開始ページから15ページ以内で「目次」と書かれたページを探し、続くページに章名が並んでいれば、そのページも目次として読みます。文字を読み取るのは各巻の最初の18ページだけです。
   - 読み取った章名は、その巻の行の下に章の行として並べます。巻の行の下にすでに章の行があるときは、置き換えてよいか確認します。目次のページが見つからなかった巻は、そのままにします。
   - 続けて、読み取った章の開始ページを探します（上の「開始ページを自動で探す」と同じ方法です）。章は、その巻の範囲（その巻の開始ページから、すぐ下の巻の開始ページの前まで）の中だけで探すので、各巻に同じ名前の章（「序章」など）があっても、ほかの巻のページになることはありません。巻の開始ページが決まっていない巻の章は確定せず、「見つからず」にします。
2. ボタンの下に「各巻の目次ページから章を読み込みました（1巻: 10章、2巻: 9章…）。」と、開始ページを探した結果を表示します。
3. 章名を確かめます。文字の読み取りなので、読み違えることがあります（縦書きの中に1文字ずつ縦に並べた英字や数字など）。章名のセルをダブルクリックして直してください。目次のページが画像だけで文字がない本では読み取れません。その場合は、巻の行の下に「行を追加」で章の行を足します。
4. 「見つからず」の章は、右のプレビューで探して「このページを選択中の行の開始ページにする」で設定します。
   - 日本語の文字認識が入っていないWindowsでは使えません。
   - 読み取った章は、開始ページを探したときに作業フォルダーに保存します。

### 3. 確かめて保存する

1. 枠に「次にすること：内容を確かめて「OK」を押してください。」と出たら、各巻の範囲と「⚠」の行がないことを確かめて、「OK」を押します。「書籍情報・目次」の枠の「巻ごとに分けて出力」が自動でオンになります（ステータスに「合本の巻があるので「巻ごとに分けて出力」をオンにしました」と出ます）。合本全体を1つのファイルにしたいときは、オフに戻します。このチェックは作業フォルダーごとに保存し、次に開いたときも同じ状態になります。
2. 「書籍情報・目次」の枠の説明で、出力する内容を確かめます。
   - 「巻ごとに分けて、5つのファイルに出力します」に続けて、巻ごとに「1. 巻名: 4〜838ページ（章 〇件、1ページ目はカラー表紙）」のように、ページの範囲と章の数を表示します（9巻目からは「…ほか〇巻」とまとめます）。どの巻にも入らないページ（合本の表紙・目次など）があれば、その範囲も表示します。
   - 「巻ごとに分けて出力」がオフのときは「いまは合本全体を1つのファイルに出力します」、巻の開始ページが足りないときは「巻ごとに分けて出力できません」と理由を表示します。
3. 「選択形式を書き出す」を押し、保存先のフォルダーを選びます。
4. 「出力内容の確認」で、巻の一覧（巻名、ページの範囲、ページ数、章の数、カラー表紙と扉のページ）と、保存するファイルを確かめます。1つの巻のページ数が合本全体に近いときは、巻の行が足りないか、開始ページが間違っています。

各巻のファイルの中身：
- ページ：その巻の開始ページから、次の巻の開始ページの前のページまで。最後の巻は最終ページまでです。1巻より前のページ（合本の表紙や目次）は出力しません。
- カラー表紙：合本では、各巻の表紙の画像が、その巻の扉の少し前（前の巻の奥付の後ろ）にあります。巻の開始ページ（扉）の前の4ページまでに色の付いたページがあれば、それをその巻の表紙とみなし、そのページから巻のファイルを始めます（表紙の後ろの注意書きのページも、その巻に入ります）。前の巻は、その表紙の前のページで終わります。章の開始ページや巻の行の開始ページ（扉）は、そのままでかまいません。色の付いたページがなければ、これまでどおり扉から始めます。自動で見つけたページが違うとき（広告や口絵のカラーページなど）や、表紙が4ページより前にあるときは、「目次と章の開始ページ」の「巻の表紙…」で、表紙のページを手で決めるか、表紙を使わないようにできます。一覧の「表紙」の列と枠では、手で決めた表紙を「表紙（手動）」、使わない巻を「表紙なし」と表示します。
- 表紙：その巻の最初のページ（カラー表紙、なければ巻の開始ページ）を表紙として扱います。サムネイル、表紙の余白、ページ番号を描かないことも、普通の出力の1ページ目と同じです。「巻ごとに分けて出力」がオンのときは、プレビューでも各巻の最初のページを表紙として扱い、余白を削りません。余白削減で本文の位置を調べるときも、書き出しと同じく各巻の表紙と1巻より前のページを除きます。巻の開始ページを変えると、プレビューも描き直します。
- ページ番号・進捗バー：巻ごとに数え直します（その巻の最初のページが1ページ目）。
- 書名：巻の行の名前です。作者・出版社は取得タブ⑧のものを使います。
- 章：その巻の行より下で、次の巻の行より上にある行のうち、開始ページがその巻の範囲にあるものです。巻の行そのものは章にしません。
- 形式・圧縮・文字太らせの比較書き出しなどの設定は、すべての巻に同じように使います。巻の数だけファイルが増えます。

ファイル名は巻の名前から作ります（ファイル名に使えない文字は「_」に置き換えます）。同じ名前のファイルがすでにあるときや、同じ名前の巻が2つあるときは、「(1)」のような番号を付け、上書きしません。

次のときは書き出しを始めず、理由を表示します。
- 開始ページが「未設定」の巻がある。
- 巻の開始ページが、一覧の順に後ろのページになっていない（2つの巻が同じページから始まる場合も含みます）。

途中で「変換をキャンセル」を押した場合や、失敗した場合は、書き終えた巻のファイルもすべて削除します。出力の記録には、各巻のファイル（巻名、ページの範囲、sha256）を残します。中間PNGの消去は、普通の出力と同じようにできます（[12章](12-raw-cleanup.md#巻ごとに分けて書き出したとき)）。ただし、1巻より前のページ（合本の表紙や目次）はどの巻のファイルにも入らないので、消去すると残りません。また、どれか1巻のファイルでも読めないときや、巻のページの範囲に重なり・抜けがあるときは、中間PNGを消去できません。

「巻ごとに分けて出力」をオフにすると、今までどおり1つのファイルに出力します。このとき巻の行も、普通の章として書き込みます。

### 例：5巻の合本（楽天Kobo）

楽天Koboの目次を読み取ると、一覧は「表紙」「目　次」「宇宙軍士官学校─攻勢偵察部隊─１」〜「…５」の7行になり、一覧の上に「合本を巻ごとに分ける（5巻）」の枠が出ます。

1. 「巻の始まりを探す」を押します。5つの巻の行が「1巻」〜「5巻」になり、各巻の扉（6・841・1682・2523・3432ページ）が開始ページに、カラー表紙（4・839・1680・2521・3430ページ）が「表紙」の列に入ります。
2. 「章を読み込む」を押します。各巻の扉のすぐ後ろにある目次から章名を読み、巻の行の下に並べて、章の開始ページを探します。
3. 枠の各巻の範囲を確かめ、「OK」を押します。「巻ごとに分けて出力」がオンになるので、そのまま書き出します。各巻のファイルは、その巻のカラー表紙から始まります。

### うまくいかないとき

| 症状 | 原因と直し方 |
|---|---|
| 2巻目の目次を読み取ると、1巻目の章が並ぶ | 2巻目の開始ページが1巻目と同じページ（または1巻目の範囲）になっています。各巻の扉は巻番号のほかは同じなので、以前の版では2巻目が1巻目の扉に照合されることがありました。枠の「⚠」の行で重なっている巻を確かめ、手順1の「やり直す」を押すか、右のプレビューで2巻目の扉を表示して「このページを選択中の行の開始ページにする」を押します。2巻目の下に並んだ1巻目の章は、手順2の「やり直す」を押すと置き換えられます |
| 巻の開始ページが「見つからず」になる | 扉の巻番号を文字で読み取れず、リーダーアプリの目次からも決まらなかった場合です。右のプレビューで扉を表示して設定します |
| 「章を読み込む」で「目次ページが見つかりません」 | 巻の開始ページから15ページ以内に「目次」と書かれたページがありません。開始ページが巻の扉より後ろになっていないか確かめます。目次のページが画像だけの本では、「行を追加」で章を足します |
| 書き出した1巻目のファイルに、2巻目以降も入っている | 巻の行が1つしかありません。手順1の「巻の始まりを探す」を押すか、ほかの巻の行を右クリックして「この行を巻にする」を選び、開始ページを設定してから書き出し直します |
| 章が巻のファイルに入らない | 章の開始ページが巻の範囲の外です（「合本を巻ごとに分ける」の枠の「⚠ 巻の範囲の外のページの章」）。章の行が正しい巻の行の下にあるか、開始ページがその巻の範囲にあるかを確かめます |
