# 1. はじめに・画面の見方

> 🧪 このマニュアルは **v0.4.9.15** を対象にしています。フォルダー版はインストーラーではありません。

> ⏳ **AVDの導入と設定には手間がかかります**: ebook2xtcを使うには、Android StudioとAVD（Android仮想デバイス）の準備が必要です。導入、日本語化、リーダーアプリの準備には時間がかかり、AVDは十数GB以上のディスクを使い、動かしている間はPCの動作も重くなります。詳しくは[2章](02-android-studio.md)をご覧ください。

## ebook2xtcでできること

ebook2xtcは、Androidエミュレーター（AVD）に表示した電子書籍リーダーアプリの読書画面を1ページずつ取得してRAW PNGとして保存し、XTEINK X4またはX3向けのXTC／XTCH（必要ならページ単位LZ4圧縮版）へ書き出すWindowsアプリです。

| 出力対象 | 出力寸法 | 原寸で取得 | 2倍で取得 |
|---|---|---|---|
| XTEINK X4 | 480×800 | 480×800 | 960×1600 |
| XTEINK X3 | 528×792 | 528×792 | 1056×1584 |

- 画像は、ADBでAndroidの画面バッファを直接受け取って取得します（ADB直接取得）。AVDのウィンドウの位置や大きさ、Windowsの表示倍率には左右されません（[5章](05-launch-avd.md)）。
- 2倍で取得したRAWは、書き出すときに出力寸法へ高品質に縮小します。
- 保護された画面は黒画像などとして返る場合があります。ebook2xtcは保護を回避せず、中央がほぼ全黒の画像は保存せずに止まります（[7章](07-capture.md)）。

## 画面の構成

画面は左右2つに分かれています。境目をドラッグすると左右の幅を変えられます。ウィンドウの配置は、次回の起動に引き継がれます。

| 部分 | 役割 |
|---|---|
| 左：設定エリア | 「取得」「出力・画質」「その他」の3つのタブ。AVDの起動、キャプチャの手順、出力の設定を行います |
| 左下：ステータス | 直前の操作の結果や、RAWを保存しなかった理由を表示します（起動直後は「準備完了」）。困ったときは、まずここを読んでください |
| 右：取得ページ | 保存したページの一覧。`000001  page_000001.png` のように、ページ番号とファイル名が並びます。重複や交互ループの候補には ⚠ が付きます |
| 右：プレビュー | 一覧で選んだページの表示。上部でプレビューの種類を選び、プレビューの下の「◀ 前ページ」「次ページ ▶」とページ番号の欄で、表示するページを移動します。これらは保存済みのページを表示するだけで、AVDのページは送りません。表示倍率の欄（全体表示／100%（原寸）／200%（画素確認））で拡大でき、拡大中はスクロールで見る場所を動かせます。「RAWと処理後を並べて比較」をオンにすると、RAWと出力後の見え方を左右に並べて比べられます |

AVDの起動や寸法の確認の結果は、「取得」タブの「事前準備」の枠内にも表示されます。

項目の横にある「?」を押すと、その項目の説明が開きます（ページ送り、DPI（密度）、リーダーアプリ、画質プリセットの内容、細い線の保護など）。

左の設定エリアでは、マウスのホイールは設定エリアのスクロールだけに使います。ポインターが選択欄や数値欄、タブの上にあっても、ホイールで設定やタブは変わりません。設定を変えるときは、クリックして選ぶか、数値を入力してください。

プレビューの種類は次の5つです。

| 種類 | 表示する内容 |
|---|---|
| RAW | 保存したPNGそのもの |
| XTC 2階調プレビュー | 現在の出力設定でXTCにしたときの見え方 |
| XTCH 4階調プレビュー | 現在の出力設定でXTCHにしたときの見え方 |
| 余白・切り出しプレビュー | 余白削減や出力用切り出しの範囲の確認。「余白」を変えると自動でこの表示になります |
| AVDライブ（密度確認） | DPI調整の直後に取得した、AVDの現在の画面（[9章](09-density.md)） |

タブごとの主な項目は、[目次ページ](index.md) の「画面の3つのタブ」にまとめています。

## 起動する

配布フォルダー内の `start_ebook2xtc.bat` をダブルクリックします。バッチファイルは、同じフォルダーの `ebook2xtc.exe` を起動します。

- `start_ebook2xtc.bat`、`ebook2xtc.exe`、`_internal`、`manual`、環境JSONは同じ配布フォルダーに置いたままにします。
- SmartScreenが警告する場合、バッチからの起動でも警告は解除されません。配布元とファイルを確認し、実行を許可できる場合にだけWindowsの案内に従ってください。管理対象のPCで禁止されている場合は管理者に確認してください。
- 設定は同じフォルダーの `ebook2xtc.ini` に保存されるため、フォルダーに書き込み権限が必要です（[13章](13-migration.md)）。
- Android SDK、AVD、リーダーアプリ、X4／X3実機は含まれません。AVDを使うには、Android SDKの `platform-tools\adb.exe` と `emulator\emulator.exe` が必要です（[2章](02-android-studio.md)）。

## 起動したときに表示されるもの

- 起動直後は「Android環境を確認しています…」と表示され、AVDの一覧と仮想化の確認を裏で行います。確認には十数秒かかることがあり、その間はアプリを閉じられません。
- AVDの一覧は読み込みますが、**AVDを自動では起動しません**。起動中のAVDがあっても、自動で設定し直すことはありません。
- フォルダー版では、同梱の環境JSONとSDKを確認します。「取得」タブ上部の「Android環境の準備」からAndroid Studioの入手、導入手順、標準AVDの設定へ進めます。準備完了後も「環境準備済み」の短い表示が残り、「導入・再設定を開く」で再確認できます（[13章](13-migration.md)）。
- 前に使った作業フォルダーにRAW PNGが残っていると、「残っている中間PNGの確認」が開きます。残すか消すかを、作業フォルダーごとに選べます（[11章](11-raw-cleanup.md)）。迷ったら「保持して続行」を押してください。

## このマニュアルを開く

「その他」タブの「マニュアルを開く」を押すと、このマニュアルが既定のブラウザーで開きます。インターネット接続は不要です。「マニュアルが見つかりません」と出た場合は、`ebook2xtc.exe` と同じフォルダーに `manual` フォルダーがあるか確認してください。

## 最初に確かめる項目

「取得」タブの「事前準備：取得方式と解像度を選んでからAVDを起動」で、AVDを起動する前に次の項目を確かめます。

1. ⓪「出力対象」：XTEINK X4 (480×800) または XTEINK X3 (528×792)
2. ①「取得方式」：ADB直接取得（選択肢はこの1つだけで、表示のみです）
3. ②「キャプチャ解像度」：原寸 または 高画質 2倍（初期値は高画質 2倍）

②に表示される寸法は、⓪で選んだ機種に合わせて変わります。選び終えたら、③からAVDを起動します（[5章](05-launch-avd.md)）。

AVDをまだ作っていない場合は、次章から順に準備します。
