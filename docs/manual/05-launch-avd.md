# 5. ebook2xtcからAVDを起動する

ebook2xtcは、起動したときにAVDを自動では起動しません。出力対象と解像度を選んでから、アプリの「起動」でAVDを立ち上げます。

> ⚠️ **方式と解像度は、起動する前に選びます**: 「起動」を押したとき、アプリは選んだ機種と倍率に合わせてAVDの画面寸法と密度を書き換え、端末フレームを無効にしてから起動します。起動した後に⓪〜②を変えた場合は、もう一度「起動」を押してください。

## 取得方式

画像は、ADBでAndroidの画面バッファを直接取得します（`adb exec-out screencap`）。取得方式はこの1つだけです。

- Windowsの表示倍率やモニターの解像度には左右されません。
- AVDのウィンドウは、ほかのウィンドウに隠れていても、縮小表示でもかまいません。
- 解像度は、原寸と高画質 2倍（初期値）から選べます。迷ったら高画質 2倍を使ってください。

> 📝 旧版にあった「Windows画面取得」（Windowsに表示されたAVD画面を取得する方式）は廃止しました。旧版でその方式で作った作業フォルダーは、開いて書き出すことはできますが、続きの取得はできません（[12章](12-resume.md)）。

## 起動の手順

1. 「取得」タブで、⓪「出力対象」をXTEINK X4またはXTEINK X3にします。
2. ①「取得方式」がADB直接取得であることを確かめ、②「キャプチャ解像度」を選びます。
3. 「③ AVDを選んで起動」の欄で、作成したAVDを選び、「起動」を押します。ボタンが「起動中…」に変わります。
4. アプリが2秒ごとにAVDの状態を確かめます。ステータスに「Android起動とウィンドウ位置を確認しています（位置 1/3回 / Android 起動待ち）」のような進み具合が出ます。ウィンドウを画面内へ寄せる補正が3回成功し、Androidの起動が完了するまで待ちます。
5. 「（AVD名）が起動しました（emulator-5554）。ADB取得は960×1600 pxです。…画面位置と取得範囲を自動設定しました。」と出たら完了です。起動したAVDは、「事前準備」の枠の③の下にある「Android AVD」欄（操作対象のAVD）で、自動的に選ばれます。
6. 「キャプチャの手順」の案内が「次の操作：① 新規作業フォルダを作成してください。」に変わったら、[7章](07-capture.md)へ進みます。

## AVDの内容を確認・削除する

③でAVDを選び、「選択AVDの詳細」を押すと、Android API、システムイメージ、保存された画面寸法・DPI、キーボードやGPUなどの設定を確認できます。AVDが起動中の場合は、ADBから取得した実際の画面寸法・密度も表示します。保存設定と起動中の値が異なることがあるため、比較するときは両方を確認してください。

不要なAVDは③で選択して「選択AVDを削除」を押します。起動中のAVDは削除できません。確認画面で実行すると、そのAVD内のアプリ、リーダーアプリのログイン状態・書籍データ、設定、スナップショットを含む内部データを完全に削除します。元には戻せません。ebook2xtcの作業フォルダーや、出力済みのXTC/XTCHファイルは削除しません。

> ⏱️ 約3分たっても起動を確認できない場合は、「（AVD名）の起動を確認できませんでした。AVD更新を押して状態を確認してください。」と表示されます。エミュレーターが起動直後に終了した場合は、終了コードが表示されます。

## すでに起動しているAVDを使う

Device Managerなどで先にAVDを起動していても、アプリの③で同じAVDを選んで「起動」を押します。

- 寸法が選んだ値と一致していれば、再起動せずにウィンドウ位置と取得範囲だけを設定します（「（AVD名）はすでに起動中です（emulator-5554）。画面内に配置しました。」）。
- 一致しない場合や、画面設定を書き換えた場合は、「（AVD名）は起動中ですが、現在の寸法は（現在の値）です。選択した960×1600を適用するためAVDを再起動します。」のように表示して、AVDを自動で再起動します。

起動中のAVDが一覧にない場合は、「Android AVD」欄の右にある「AVD更新」を押してください。

## AVDの画面寸法とウィンドウの大きさ

AVDの仮想画面の寸法と、Windows上で見えるウィンドウの寸法は、別の値です。エミュレーターのウィンドウがモニターに合わせて縮小表示されても、取得画像は選んだ解像度のままです。

## 解像度や倍率を変えたいとき

作業フォルダーを作った後は、②解像度を変更できません。1ページ目を保存した後は、⓪出力対象も変更できません。1つの作業フォルダーの中で、機種・倍率は混在しません。変えたい場合は「キャプチャを終了」してから選び直し、「起動」を押して、新しい作業フォルダーを作ります。

## ページ送り

AVDへページ送りのキーを送る「◀ 前ページ」「次ページ ▶」は、作業フォルダーを作った後、③でリーダーアプリを調整している間に使います（[7章](07-capture.md)）。キーの向きは「本の読み方向」に合わせて決まります。
