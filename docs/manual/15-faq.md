## 起動と配布

| 状況・表示 | 確認すること |
|---|---|
| `start_ebook2xtc.bat` から起動できない | バッチと `ebook2xtc.exe` が同じフォルダーにあるか確認します。`_internal` フォルダーも必要です（[1章](01-getting-started.md)） |
| WindowsのSmartScreenが警告する | バッチは同じフォルダーのEXEを起動するだけで、SmartScreenの警告を解除しません。配布元とファイルを確認し、実行を許可できる場合にだけWindowsの案内に従ってください。管理対象のPCでは管理者に確認します |

## AVDとAndroid

### AVDの準備と起動

| 状況・表示 | 確認すること |
|---|---|
| アプリを起動してもAVDが起動しない | 仕様です。⓪〜②を選び、③でAVDを選んで「起動」を押します（[5章](05-launch-avd.md)） |
| 「Android Emulatorが見つかりません。」／AVDが一覧に出ない | SDK ManagerでAndroid EmulatorとPlatform-Toolsを入れたか、SDKの場所に `emulator\emulator.exe` と `platform-tools\adb.exe` があるかを確認します。環境変数を変えた場合は、アプリを起動し直します（[2章](02-android-studio.md)） |
| Device Managerなどで「Google generic no longer exists as a device」と表示される | 過去版のebook2xtcが付けた端末名が原因の場合があります。ebook2xtcの③で対象AVDを選び「起動」を押すと、無効な端末名を修復します。AVDが起動中の場合は、設定を反映するため再起動されることがあります。リーダーアプリのログインや書籍データは削除しません |
| 外部で起動したAVDが「Android AVD」欄に出ない | 「事前準備」の枠の③の下にある「AVD更新」を押します |
| 「…の起動を確認できませんでした。」 | 約3分待っても起動を確認できませんでした。AVDのウィンドウでAndroidが起動しているか確認し、「AVD更新」を押します |
| 「このPCではAVDの実行に使う仮想化を現在利用できません」 | 「準備を再確認」で再起動が後で必要になる確認画面が出ます。**OK** ならAVD作成を続け、キャンセルならセットアップを保留します。AVDを起動する前に「Windowsの機能を開く」から「Windows ハイパーバイザー プラットフォーム」を有効にし、**Windows PC本体を一度再起動**します。警告がなければ再起動は不要です（[2章](02-android-studio.md)） |
| 「…のEmulatorが起動直後に終了しました（終了コード …）。」 | Android StudioのDevice Managerから同じAVDを起動して、エラーを確認します。PCのメモリや仮想化の設定が原因のことがあります |
| ADBサーバーを起動できない | アプリは、設定済みのAndroid SDKの `adb.exe` を優先し、応答しないADBサーバーを再起動します。Windowsが既定のポート5037での待ち受けを拒否した場合は、5038〜5043も順に試し、成功したポートをAVDにも引き継ぎます。すべて失敗する場合は、エラーに表示されたADBのパスとポートの診断を確認し、Android Studioなど別のSDKを使うソフトを終了して「AVD更新」をやり直します |
| System Imageを入れたのに「標準環境をセットアップ」が押せない | 「準備を再確認」を押し、表示されたSDKの場所とAndroid Studioの **Android SDK Location** を比較します。必要なのはAndroid 15／Google Play／x86_64のイメージです。Google APIs版、Tablet版、16 KB版は別物です。SDKの場所が違う場合は「SDK保存先を指定（認識しない場合）」を押します（[2章](02-android-studio.md)） |
| Playストアがない | AVDのシステムイメージがGoogle Play対応か確認します。Google APIsだけのイメージには、Playストアが含まれないことがあります（[2章](02-android-studio.md)） |
| 取得する画面の解像度が合わない | 起動前に⓪と②を選び、アプリの「起動」からAVDを立ち上げ直します。寸法が違えば、アプリがAVDを再起動して合わせます。AVDのウィンドウの見た目の大きさは関係ありません（[5章](05-launch-avd.md)） |

### Androidの言語・入力・画面

| 状況・表示 | 確認すること |
|---|---|
| Androidまたはリーダーアプリが英語 | Androidの「System languages」で日本語を一番上にし、Android 13以降ではリーダーアプリの「App languages」も確認して、リーダーアプリを再起動します。リーダーアプリのアカウント地域は別の設定です（[3章](03-japanese-and-reader.md)） |
| ログイン欄に入力できない | AVDの「Enable Keyboard Input」を有効にし、AVDのウィンドウを前面にして入力欄をクリックしてから、PCのキーボードで入力します（[4章](04-keyboard-and-sleep.md)） |
| リーダーアプリのID欄でかな入力から切り替えられない | AVD内のGboardならスペースキーを長押しして英語キーボードを選びます。PC側の日本語IMEならタスクバーの「あ」を「A」にするか、Windowsキー＋Spaceで「ENG」を選びます。詳しい手順は[4章](04-keyboard-and-sleep.md)を参照してください |
| 取得中にAVDの画面が消える | 「その他」タブの「AVDの起動時に、画面が消えない設定にする」をオンにして、AVDを起動し直します。ご自分で設定する場合は、Developer optionsの「Stay awake」、AVDの充電状態、Windows PCのスリープ設定を確認します（[4章](04-keyboard-and-sleep.md)） |

## キャプチャ

### 取得の準備（④〜⑨）

| 状況・表示 | 確認すること |
|---|---|
| 「④ 新規作業フォルダを作成」が押せない | ③で「起動」を押して、取得画面を設定していません。案内に「次の操作：③で対象AVDを選び「起動」を押して取得画面を設定してください。」と出ます |
| 「⑥ リーダーアプリを開く（書籍選択・文字調整）」が押せない | ページを保存済みの作業フォルダーでは押せません。続きは「保存済みページの続きから連続取得」を使います |
| 「リーダーアプリを開けません」 | リーダーアプリがインストールされているか、AVDの寸法が選んだ値と一致しているかを確認します |
| 「取得した画面 …×… が、取得開始時の設定（…）と一致しないため、保存しませんでした。」 | 取得の途中でAVDの画面サイズが変わりました。取得を止め、AVDの画面サイズを取得開始時の機種・倍率に戻してから、続きを取得します |
| ⑨が押せない | ⑦で表紙のプレビューを取得していません。⑦を押し、確認で「はい」を選びます |

### リーダーアプリの確認と章探し

| 状況・表示 | 確認すること |
|---|---|
| 「Androidに○○が表示されていません」 | 書名・目次の読み取りや章の開始ページ探しで使うリーダーアプリが、Androidの画面の前に出ていません。メッセージには、今前に出ているアプリ（「今は楽天Koboが表示されています」など）も表示します。前に出ているアプリが分からないときは「確認できませんでした」と表示します。⑥でそのリーダーアプリを開き、本を開いた画面にしてから、もう一度実行します。章の開始ページ探しは、作業フォルダーの本を取得したリーダーアプリで行います（[11章](11-book-info.md)） |
| 「リーダーアプリの確認」（この作業フォルダーには、本を取得したリーダーアプリの記録がありません） | 前の版で作った作業フォルダーなどで、書名・目次を読み取る前と、章の開始ページ探しでページの文字から見つからない章が残ったときに出ます。その本を取得したリーダーアプリと同じなら「はい」、違うなら「いいえ」を押します。「はい」は作業フォルダーに記録され、次からは聞きません（[11章](11-book-info.md)） |
| 「Androidの画面に表示中のアプリを確認できませんでした」 | AVDが応答していないか、画面の切り替え中です。AVDの画面を確かめてから、もう一度実行します。章の開始ページ探しは、この場合ページの文字だけで探します |
| 「〇章は、その章の巻の開始ページが決まっていないため、見つからずにしました」 | 合本の巻の開始ページを先に設定してから、その章の「自動」にチェックを付けて探し直します（[11章](11-book-info.md#合本版を巻ごとに分けて出力する)） |
| 「この作業フォルダーの本は○○で取得しています。…」 | ページを保存済みの作業フォルダーを開いたまま、取得タブで別のリーダーアプリを選びました。開いている作業フォルダーの本は、元のリーダーアプリのまま扱います。別のリーダーアプリの本は、④で新しい作業フォルダーを作ってから取得します |

### 連続取得が止まる・遅い

| 状況・表示 | 確認すること |
|---|---|
| 連続取得中、ページごとに止まる時間が違う | 仕様です。ページごとに、最短待機 a〜最大待機 b（初期値0.3〜1.5秒）の範囲から待ち時間を無作為に選び、その時間がたってから保存します。選んだ値は作業フォルダーの `session.json` に `T_seconds` として残ります。間隔をそろえたい場合は、aをbに近づけます（その分遅くなります）。bは「ページ変化なし」と判定するまでの制限時間も兼ねます。初期値の1.5秒は開発PC（Ryzen 5 5500）での測定から決めた値なので、これより下げるのはおすすめしません。非力なPCで「ページ変化なし」で止まることが多い場合は、2.0〜2.5秒に延ばします（[8章](08-stability.md#非力なpcで使うとき)） |
| 「ページ変化がないためRAWは保存せず、…」 | 自動で再確認とページ送りのやり直しを行います。キーを送った後の変化なしが3回に達すると巻末候補として止まります。巻末でなければ、リーダーアプリの画面を確認して「保存済みページの続きから連続取得」で再開します（[8章](08-stability.md)） |
| 「表示の安定を確認できず停止しました。今回のページは未保存です」 | ページ描画やアニメーションが、最大待機時間内に落ち着いていません。保存の失敗ではなく、そのページはまだ保存していません。bを少し長くするか、微細なちらつきだけが原因ならεを少し大きくします。表示された秒数・検査枚数の見方は[8章](08-stability.md#待機時間の内訳)にあります |
| 「プレビュー更新が遅れています。取得と保存は進んでいます。」 | 右ペインの表示が遅れているだけです。保存済みページ数が増えていれば、取得は続いています。取得を止めると、最後に保存したページを表示し直します（[7章](07-capture.md#連続取得中のプレビュー)） |
| 「保存は完了しています。表示を更新できません」 | 縮小画像を作れなかったページがあります。保存は終わっています。次のページの表示で元に戻ります |
| 「診断ログを書き込めません（取得と保存は続けています。…）」 | 診断ログの保存先に書き込めません（空きがない、ほかのアプリが開いているなど）。取得は続きます。しばらくして自動で書き込みを再試行します。RAWや台帳の保存先に空きがない場合は、別に「空き容量不足」で止まります |
| 「取得領域の中央がほぼ全黒です。…」 | 画面保護、または表示の異常の可能性があります。本当に黒いページだと確認できたときだけ、「全黒ページも許容（次の1ページだけ）」をオンにして続きから取得します（[8章](08-stability.md)） |
| 「直前ページとの完全重複を検出し、後のページ（…）を削除しました。」 | 巻末で同じ画面を2回取得したときの動きです。本の途中で出た場合は、ページ送りが効いていないので、リーダーアプリの画面を確認して続きから取得します（[7章](07-capture.md)） |
| 「重複候補」「交互ループ候補」で止まった | RAWはすべて保持しています。一覧の ⚠ の付いたページを見比べ、リーダーアプリの表示位置を直してから続きを取得します。前のページと同じページが1枚だけ出たとき（合本の各巻の注意書きなど）は、⚠ を付けるだけで止まりません。止まるのは、同じ並びのページが5ページ続いたときです |
| 「空き容量不足のためセッションを停止しました。」 | 保存先のドライブの空きを作り、「⑤ 保存済み作業フォルダを開く」で再開します（[6章](06-before-capture.md)） |

## 診断ログと診断情報の保存

連続取得の様子を後から調べられるよう、ebook2xtcは診断ログを記録します。どの版・ビルドで動いたか、ページ送り・画面取得・安定判定・リーダーアプリの確認・保存（RAW・取得記録・台帳）の各段階にかかった時間、プレビューの遅れ、画面が5秒以上応答しなかった時間などを記録します。

- 連続取得を始めると、作業フォルダーの `diagnostics\capture.jsonl` に記録します。作業フォルダーを開く前の記録は、アプリのフォルダーの `logs` フォルダー（書き込めない場合は `%LOCALAPPDATA%\ebook2xtc\logs`）に記録します。
- 1ファイル5 MBで新しいファイルに切り替え、古いものは4つまで残します（合計25 MBまで）。古い順に消すのは診断ログだけで、RAWや台帳は消しません。
- ページの画像、本文、ログイン情報は記録しません。診断ログを消しても、取得・再開・出力には影響しません。0.4.9.23以前の作業フォルダーも、診断ログなしでそのまま開けます。
- 書き込めない間の記録は、上限を超えると省きます。省いた件数は、書き込めるようになったときに記録します。
- 診断ログは記録するだけです。表示が遅れたことを理由に、AVDやリーダーアプリ、ebook2xtcを自動で再起動したり、ページを余分に送ったりはしません。

不具合を相談するときは、「その他」タブの「診断情報を保存…」を押して保存先のフォルダーを選びます。今回の起動の記録と設定の要約を1つのファイルにまとめます。ユーザー名やホームフォルダーの場所は置き換え、書名・作者は含めません。ファイルは自動では送信しないので、必要に応じて自分で渡してください。

## 再開・出力

| 状況・表示 | 確認すること |
|---|---|
| 「セッションを再開できません」 | 親フォルダーではなく、`ebook2xtc_…` または旧版の `s4capture_…` の作業フォルダーを選んだか確認します。RAWを手で動かした場合は、元に戻します（[13章](13-resume.md)） |
| 「中間PNGは削除済みです」 | その作業フォルダーは、出力後にRAWを消去しています。再開・再出力はできません（[12章](12-raw-cleanup.md)） |
| 「○ページ目のRAWまたは取得記録がありません。」 | `raw` フォルダーの画像か `.capture.json` を、エクスプローラーで削除または移動していないか確かめます。消したファイルを元の場所に戻すと開けます。最後の不要なページは、ファイルを消さずに「このページ以降を取り除く」で出力から外します（[10章](10-export.md)） |
| 本の最後に不要な画面（レビューの依頼など）が入った | 右ペインでその画面を表示し、「このページ以降を取り除く」を押します（[10章](10-export.md)） |
| 「選択形式を書き出す」が押せない | ページを1枚も保存していない、取得中または連続取得中、⑥〜⑦の準備中、書き出しの最中、のいずれかです。中間PNGを消去済みの作業フォルダーでも書き出せません |
| 「対応外のRAW寸法です」 | ⓪出力対象が、取得したときの機種と同じか確認します（[10章](10-export.md)） |
| 書き出し中、PCの動作が重くなる | 24ページ以上の本は、複数の作業プロセスでページを並べて変換するため、CPUの使用率が高くなります。数を減らしたいときは、環境変数 `EBOOK2XTC_PAGE_WORKERS` に上限の数を指定してから起動します（`1` で並べずに変換します。[10章](10-export.md)） |
| 「出力記録を保存できません」 | 書き出しは完了していますが、台帳に記録できませんでした。RAWを消去しないでください。作業フォルダーの書き込み権限と空き容量を確認します |
| 「途中まで出力したファイルを削除できませんでした: … は … に残っています（…）」 | 書き出しを取り消すときに、ファイルを消せなかったか、元の名前に戻せなかった場合です。表示された場所（`.e2x_remove_` で始まる名前のこともあります）にファイルが残っています。理由が「別の処理のファイル」なら、中身を確かめて、必要なら元の名前に戻します。「この出力のファイル」なら、不要なので削除してかまいません |
| 「別の処理が置き換えたファイルは、削除せずに残しました」 | 書き出しの取り消し中に、別の処理が同じ名前のファイルを作っていました。そのファイルは消さずに残しています |
| 「出力中に同じ名前のファイルが作られたため、出力を取りやめました」 | 書き出しの途中で、別の書き出しなどが同じ名前のファイルを作りました。そのファイルはそのまま残し、今回の出力は取り消しています。別の名前を選ぶか、そのファイルを確かめてから書き出し直します |
| 「書き出し設定を保存できません」（アプリを閉じるとき） | 最後に変えた書き出し設定を作業フォルダーへ保存できませんでした。次に開いたときは前の設定に戻っているので、設定し直します。作業フォルダーの書き込み権限と空き容量を確認します |
| 中間PNGの確認に「保持必須・消去不可」と出る | 理由の欄を確かめます。読めない出力ファイルがある、巻ごとの出力のページ範囲に抜けがある、退避したページだけが残っている、などの場合はRAWを保持します（[12章](12-raw-cleanup.md)） |
| 変換が止まる・失敗する | 元のRAWとセッション台帳を残し、空き容量・保存先・表示されたエラーを確認します。途中まで書かれたファイルを、手作業で完成扱いにしないでください |
| 文字が読みにくい | 同じRAWから、余白、文字太らせ、しきい値、ディザ、XTC／XTCHを1つずつ変えてプレビューし、候補を比べます。最終的な判断は実機の表示で行います（[10章](10-export.md)） |
| 「環境プロファイルの読み込みは、取得と変換を停止してから行ってください。」 | 連続取得を「停止（Esc）」で止めるか、変換が終わるのを待ってから読み込みます。開いている作業フォルダーは、読み込む前に閉じます。アプリの再起動は不要です（[14章](14-migration.md)） |
