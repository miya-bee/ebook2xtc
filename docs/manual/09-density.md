# 9. DPI調整で表示を試す

リーダーアプリの文字の配置や改ページを確かめやすくするため、AVDの表示密度（DPI）を変えて、右ペインで実際の画面を確かめられます。

> 🕒 **変更できるのは③の準備中だけです**: 作業フォルダーを作った後、手順③でリーダーアプリを開き、書籍や文字を調整している間だけDPIを変更できます。④で表紙のプレビューを始めた後や、1ページでも保存した後は変更できません。

## 使い方

1. 作業フォルダーを作り、手順③でリーダーアプリを開いて、書籍を選び、文字サイズなどを調整します（[7章](07-capture.md)）。
2. 「③ リーダーアプリで書籍・文字を調整中」の「DPI（密度）」に値を入れます。範囲は72〜1000 dpiで、矢印ボタンでは4 dpiずつ変わります。初期値は320 dpiです。
3. 「適用してプレビュー」を押します。アプリが密度を変え、画面の寸法が変わっていないことを確かめてから、右ペインを「AVDライブ（密度確認）」に切り替えて、リーダーアプリの現在の画面を表示します。
4. 表示を見ながら、値を変えて繰り返します。
5. 「320 dpiに戻す」を押すと、標準の320 dpiをAVDへ明示的に設定します。

欄の右には「現在: 280 dpi（AVD本来 160 dpi / ebook2xtc標準 320 dpi）」のように表示されます。AVD本来の物理密度と、アプリの「320 dpiに戻す」ボタンが設定する値は別々に示します。

密度を変えても、画面の寸法（解像度）は変わりません。取得したRAWと出力の寸法も、これまでどおり選んだ機種と倍率で決まります。

## DPIを変えると何が変わるか

- DPIを下げると、画面の四隅に見える余白が少なくなる場合があります。
- 1ページに入る文字数、改ページの位置、四隅の余白に影響する場合があります。

ページを取得すると、セッション台帳と各ページの取得記録に、その取得時点の物理密度・上書き密度・実効密度を記録します。ADBから読み取れなかった場合は `null` として記録します。

> 🔎 **文字サイズを変える機能ではありません**: 同じページを200 dpiと160 dpiで比べた範囲では、文字の画素寸法の中央値はどちらも25×32 pxで、フォントサイズの変化は確認できませんでした。この結果は試したページでの観察で、ほかの本やページで同じ結果になるとは限りません。文字の大きさはリーダーアプリの文字サイズで決め、DPIは余白や文字の配置、改ページを確かめるための調整として使ってください。

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| 「密度変更後の画面が黒いままでした。」 | 描画が追いついていません。少し待ってから、もう一度「適用してプレビュー」を押します |
| 「DPIはセッション作成後、③でリーダーアプリを開いて書籍・文字を調整している間に変更できます。」 | ③を押した後、④を押す前の段階で操作します |
| 「ADBが見つからないため、密度を変更できません。」 | Android SDKのPlatform-Toolsを確認します（[2章](02-android-studio.md)） |

## 密度の設定はAVDに残ります

DPIの設定は、ebook2xtcを閉じてもAVDに残ります。試した後で「320 dpiに戻す」を押すか、次の作業で希望する値を適用し直してください。AVD環境を書き出すと、変更した密度も記録されます（[13章](13-migration.md)）。
