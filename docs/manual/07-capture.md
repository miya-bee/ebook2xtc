# 7. 作業フォルダーの作成とキャプチャ

「取得」タブの「キャプチャの手順」に、番号付きのボタンが上から順に並んでいます。押せるボタンだけが有効になり、青い枠の「次の操作：…」に、いま行うことが表示されます。この章では、新しい作業フォルダーを作ってから連続取得を終えるまでを説明します。

> 📁 **作業フォルダーとセッション**: 画面上の「作業フォルダー」は、1冊分のキャプチャの単位です。アプリの内部やメッセージでは、同じものを「セッション」と呼ぶことがあります。

## 作業フォルダーの中身

| ファイル・フォルダー | 内容 |
|---|---|
| `session.json` | セッション台帳。設定、ページ一覧、取得の試行記録、出力記録を保存します |
| `raw\page_000001.png` | 取得したRAW画像。ページ番号は6桁です |
| `raw\page_000001.png.capture.json` | そのページの取得記録（取得方式、寸法、ハッシュ、安定判定の値など） |
| `書名 - 作者.xtc` など | 書き出した出力。既定の保存先は作業フォルダーです（[10章](10-export.md)） |

## 作業フォルダーを作る

1. ⓪「出力対象」と②「キャプチャ解像度」を選び、③でAVDを選んで「起動」を押します（[5章](05-launch-avd.md)）。「起動」を押していないと、①のボタンは押せません。
2. 「① 新規作業フォルダを作成」を押し、保存先の親フォルダーを選びます。ダイアログは前回選んだ親フォルダーから開きますが、別の場所へ変更できます。OneDriveなどの同期フォルダーと関係のないローカルディスクを推奨します。
3. 親フォルダーの中に、`ebook2xtc_20261030_143015_1a2b3c4d` のような「日時＋識別子」の作業フォルダーが作られます。以前のバージョンで作成した `s4capture_…` のフォルダーも、そのまま開いて再開できます。

既存の作業を続ける場合は、「② 保存済み作業フォルダを開く」で、親フォルダーではなく作業フォルダー自体を選びます（[12章](12-resume.md)）。

## 書籍・読み方を設定する

「書籍・読み方」の枠で、次の項目を設定します。入力した内容は、すぐにセッション台帳へ保存されます。

| 項目 | 選択肢・初期値 | 説明 |
|---|---|---|
| ページのレイアウト | リフロー型本文（初期値）／未指定／固定レイアウト（漫画・図版中心など） | 固定レイアウトを選ぶと「レイアウトの注意」が表示されます。画質プリセットは本文向けなので、出力プレビューを見て手動で判断してください |
| 本の読み方向 | 未指定／右から左（縦書き等）／左から右（横書き等） | 次ページのキーの向きを決めます。右から左は←キー、左から右は→キーで次ページへ進みます。未指定は右から左として扱います |

書名と作者は、表紙を確認した後に⑤で入力します。「ページ安定判定（詳細設定）」は、初期値から始めてください（[8章](08-stability.md)）。

## ③ リーダーアプリで本を選び、文字を調整する

使うリーダーアプリは、「取得」タブの「リーダーアプリ」欄で選んでおきます（[3章](03-japanese-and-reader.md)）。未選択のまま③を押すと、AVDにインストールされたアプリの一覧が表示されるので、そこで選びます。

1. 「③ リーダーアプリを開く（書籍選択・文字調整）」を押すと、AVDの寸法を確かめてからリーダーアプリをAndroid上に開きます。本の選択や文字の調整をしやすくするため、選択中のエミュレーターを最小化から復元してWindows画面の前面に表示します。リーダーアプリのアイコンを押したときと同じで、トップ画面へは移動しません。本を開いたままなら、その本のページがそのまま表示されます。
2. リーダーアプリで本を選び、文字サイズ・行間・余白などを調整します。この準備中はRAWを保存しません。
3. ③のすぐ下に「③ リーダーアプリで書籍・文字を調整中」の欄があります。数ページ先の見た目を確かめたいときは、「ページ送り」の「次ページ ▶」を使えます。表紙へ戻るときは「◀ 前ページ」も使えます。
4. 必要なら、同じ欄の「DPI（密度）」で表示密度を試せます（[9章](09-density.md)）。ページ送りとDPIを使えるのは、この段階（④のプレビュー前）だけです。連続取得中や④の後に押せると、取得するページがずれるためです。作業フォルダーを作る前にページを動かしたいときは、AVDの画面を直接操作してください。

ページ送りのボタンは、選択中のAVDへキーを1回送ります。RAWは保存せず、右ペインの保存済みプレビューも動きません。キーの向きは「本の読み方向」に合わせて決まります。

③は、ページを1枚も保存していない作業フォルダーでだけ押せます。

## ④ 表紙に戻ってプレビューする

1. リーダーアプリで、本の表紙まで手で戻ります。
2. 「④ リーダーアプリで表紙に戻り、プレビュー確認」を押します。「表紙に戻しましたか？」と確認されるので、表紙が表示されていれば「Yes」を押します。
3. 右ペインに表紙が表示されることを確認します。違う画面が写った場合は、リーダーアプリで表紙に戻ってから④を押し直します。何度でもやり直せます。

## ⑤ 書名・作者を入力する

「⑤ 表紙確認後：書籍情報」の書名と作者は、④でプレビューを取得すると入力できるようになります。ここで入力した内容は、セッション台帳に保存され、出力ファイル名（`書名 - 作者.xtc`）に使われます。空欄でも取得はできますが、ファイル名が `output.xtc` になります。

## ⑥ 連続取得を始める

1. 「⑥ この表紙で連続取得を開始」を押すと、表示中の画面をあらためて取得し、④でプレビューした表紙と同じ画面であることを確かめてから、1ページ目として保存します。その後は、自動でページを送りながら取得を続けます。通常の取得には、ページ数の上限がありません。表紙と違う画面だった場合は保存せずに止まるので、リーダーアプリで表紙に戻し、④からやり直してください。
2. 連続取得中は「連続取得中です。停止する場合は下の停止ボタンを押してください。」と表示されます。
3. 止めるときは「停止（Esc）」ボタンを押すか、`Esc` キーを押します。処理中のページを保存し終えてから、次のページへ進まずに止まります。

> ⏹️ **止めるときの注意**: `Esc` キーは、ebook2xtcのウィンドウが選ばれているときだけ効きます。AVDのウィンドウを選んだまま `Esc` を押すと、Androidの「戻る」として扱われ、リーダーアプリが本の画面から戻ることがあります。確実に止めたいときは「停止（Esc）」ボタンを押してください。

> 🔤 **フォントテスト**: ⑥を押す前に「フォントテスト：指定ページで停止」をオンにすると、「スナップ終了ページ」（初期値10、1〜99999）のRAWを保存した直後に止まり、「出力・画質」タブへ切り替わって完了アラートが表示されます。短い出力で文字サイズや画質を確かめた後、「保存済みページの続きから連続取得」を押すと、制限なしで巻末まで取得を続けます。スナップ終了ページの値は次回の起動にも引き継がれます。

## 連続取得が止まるとき

連続取得は、次の場合に自動で止まります。ステータスの表示と、右ペインの最後のページを確認してください。

| 状況 | アプリの動き | RAW |
|---|---|---|
| ページ変化なし | 1回目は、キーを送らずに表示を再確認し、それでも変わらなければ次ページキーを送り直します。ページ送り後の変化なしが3回に達すると巻末候補として止まります。キーを送らない再確認は回数に含みません | 保存しない |
| 画面が安定しない | 最大待機時間内に描画が落ち着かなかったので止まります（[8章](08-stability.md)） | 保存しない |
| 直前のページと画素が完全に一致 | 「同一ページ／白紙も許容」がオンなら、両方を保存して重複候補として停止します。リーダーアプリの表示位置を確認してから「保存済みページの続きから連続取得」で再開できます。オフなら後のRAWを削除し、「ページ変化なし」と同じ再確認を行います | 設定により両方保持、または後の1枚を削除 |
| 直前以外のページと画素が完全に一致 | 「重複候補」と表示し、一覧に「⚠ 000012ページと完全一致」を付けて止まります | 両方を保持 |
| 2ページが交互に繰り返される | 「交互ループ候補」と表示し、一覧に ⚠ を付けて止まります | すべて保持 |
| 前のページによく似ている | 「類似候補」と表示し、一覧に「⚠ …ページに類似（距離…）」を付けます。取得は続けます | 保持 |
| 中央がほぼ全黒・ほぼ全白 | 表示異常や画面保護の可能性があるため、確認待ちで停止します | 保存しない |
| Androidの画面上でリーダーアプリ以外が表示された／表示中のアプリを確認できない | 誤った画面を取得しないよう、確認待ちで停止します | 保存しない |
| 空き容量が足りない | セッションを中断します（[6章](06-before-capture.md)） | 保存しない |

巻末の内容そのものは、自動では判定しません。止まった位置が本当に巻末か、右ペインの最後のページとリーダーアプリの画面で確かめてください。

> ⬛ **黒いページを保存するとき**: 黒い扉や挿絵など、本当に黒いページだと画面上で確認できたときだけ、「ページ安定判定（詳細設定）」の「全黒ページも許容（次の1ページだけ）」をオンにして、続きから取得します。1ページ保存すると自動でオフに戻ります。画面保護の回避は行いません。

> ⬜ **白紙ページを保存するとき**: リーダーアプリ上で白紙ページだと確認できた場合だけ、「白紙ページも許容（次の1ページだけ）」をオンにして再開します。画面変化の検出は有効なままで、白紙ページを1枚保存すると自動でオフに戻ります。「同一ページ／白紙も許容」をオンにする必要はありません。

確認待ちで停止したときは、リーダーアプリに戻って画面と表示位置を確認してください。保存済みページがある作業では、再開時に現在のリーダーアプリのページ位置を確認する選択肢が表示されます。白紙ページは専用チェックで次の1ページだけ許可できます。「同一ページ／白紙も許容」は画面変化の確認を省略するため、白紙ページの例外には使わないでください。リーダーアプリ内の警告や確認画面をすべて自動で見分ける機能ではないため、画面を目視してから再開してください。

## 1ページずつ取得する（任意）

「1ページずつ取得（任意）」の2つのボタンは、連続取得をしていないときに使えます。

| ボタン | 動き |
|---|---|
| 現在のページを保存 | いま表示しているページを、ページを送らずに保存します |
| 次ページへ進み、1ページ保存 | 次ページキーを1回送り、画面の変化と安定を確かめてから保存します |

## 続きから取得する

1ページ以上保存した作業フォルダーでは、⑥の代わりに「保存済みページの続きから連続取得」を使います。リーダーアプリが最後に保存したページを表示していることを確かめてから押してください。前回、ページを送った後に保存できずに終わった場合は、「○ページ目は表示済みで未保存です」と案内され、ページを送らずに現在のページから保存します。

## キャプチャを終える

「キャプチャを終了」を押すと、セッションを完了状態にして台帳を保存します。連続取得中は押せないので、先に停止してください。終了した作業フォルダーも、後から「② 保存済み作業フォルダを開く」で開き直し、書き出しや続きの取得ができます。
