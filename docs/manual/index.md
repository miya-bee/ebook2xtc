# ebook2xtc 操作マニュアル

電子書籍リーダーアプリの読書画面をAndroidエミュレーター（AVD）から取得してRAW PNGとして保存し、XTEINK X4・X3向けのXTC / XTCH形式へ変換するWindowsアプリの使い方ガイドです。X4は480×800、X3は528×792で出力します。

このマニュアルは **v0.4.0** のPython開発版と、ポータブルフォルダー版（`ebook2xtc.exe`）を対象にしています。フォルダー版はインストーラーではありません。

> 🧪 **開発版です**: X3は形式・寸法の検査まで対応しましたが、X3実機と各ファームウェアでの読み込みは確認していません。対応状況は [15. 対応状況と安全上の注意](15-status.md) にまとめています。

> 🔒 **画面保護は回避しません**: DRMや画面保護で取得できない画面（黒画像として返る画面など）は保存せずに停止します。試験には利用許諾を確認した書籍を使ってください。

> 🤖 **AVDの準備がまだの方へ**: Android Studioの入れ方からAVDの作成、日本語化、リーダーアプリの準備までを [2章](02-android-studio.md)〜[5章](05-launch-avd.md) で順に説明しています。配布版では、同梱の環境JSONを自動検出し、「標準環境をセットアップ」でAVDの手作業作成を省けます（[13章](13-migration.md)）。

## 基本の流れ

アプリの「取得」タブには、番号付きの手順が上から順に並んでいます。

1. ⓪「出力対象」（X4／X3）と②「キャプチャ解像度」を選ぶ（①「取得方式」はADB直接取得の1つだけです）
2. AVDを選んで「起動」を押す（[5章](05-launch-avd.md)）
3. 「① 新規作業フォルダを作成」を押す（[7章](07-capture.md)）
4. 「③ リーダーアプリを開く」で本を選び、文字を調整する
5. 「④ リーダーアプリで表紙に戻り、プレビュー確認」で表紙を確かめる
6. ⑤で書名・作者を入力し、「⑥ この表紙で連続取得を開始」でページを取得する
7. 「出力・画質」タブでXTC／XTCHを書き出す（[10章](10-export.md)）
8. 書き出しに満足したら、中間PNGを消去する（[11章](11-raw-cleanup.md)）

画面の「次の操作：…」の案内と、押せるボタンが、手順に合わせて切り替わります。

## 画面の3つのタブ

左側の設定エリアは3つのタブに分かれています。右側は、取得したページの一覧とプレビューです。

| タブ | 主な項目 | 説明している章 |
|---|---|---|
| 取得 | Android環境の準備（Android Studioの入手・標準AVDの設定）、事前準備（出力対象・取得方式・解像度・AVDの起動）、書籍・読み方、キャプチャの手順（①〜⑥、③の調整中のページ送り・DPI調整、1ページずつ取得）、ページ安定判定（詳細設定） | [2章](02-android-studio.md)、[5章](05-launch-avd.md)、[7章](07-capture.md)、[8章](08-stability.md)、[9章](09-density.md) |
| 出力・画質 | 形式・画質・画像処理（形式、圧縮、プリセット、しきい値、余白、文字太らせのオン／オフと太さ、切り出し、ディザ）、書き出し | [10章](10-export.md) |
| その他 | AVD環境の移行、操作マニュアル、アプリの配色 | [13章](13-migration.md) |
