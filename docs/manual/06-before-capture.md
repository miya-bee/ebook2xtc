# 6. キャプチャ前の準備

キャプチャを始める前に、AVDとWindowsの状態を整えます。長い本では数百ページを連続で取得するため、途中で通知やスリープに邪魔されないようにします。

## 確認すること

1. [2章](02-android-studio.md)〜[5章](05-launch-avd.md)を終え、AVDでAndroidが日本語で表示され、リーダーアプリにログインでき、対象の書籍を開けることを確認します。本の選択と文字の調整は、手順⑥の前でも後でもかまいません。⑥はリーダーアプリを開くだけで、表示中の画面は変えません。試験には、利用許諾を確認した書籍を使ってください。
2. キャプチャ中の通知を抑えるため、Androidのクイック設定から「サイレント モード」、または「モード」→「サイレント モード」を手動で有効にします。必要なら、通知フィルターで画面表示も抑えます。
3. Windowsの通知は、Android側のサイレントモードでは止まりません。長時間の取得では、必要に応じてWindowsの「応答不可」も有効にします。取得画像はADBで受け取るので、Windowsの通知が画像に写ることはありません。
4. Developer optionsの「Stay awake」を有効にし、Windowsのスリープまでの時間を延ばします（[4章](04-keyboard-and-sleep.md)）。
5. 作業フォルダーを作る親フォルダーの空き容量を確認します。2倍の取得では、原寸の4倍の画素数のPNGを保存します。

> 🔔 **通知の設定は自動では変わりません**: ebook2xtcは、通知モードを自動で変更しません。AndroidのサイレントモードでもSystem通知や重要な通知が表示される場合があります。作業が終わったら、AndroidとWindowsの両方の設定を元へ戻してください。

## 空き容量の確認

ebook2xtcは、ページを取得するたびに、次の1ページ分と予備の64MBが空いているかを確かめます。保存済みが10ページ未満のうちは非圧縮の寸法から多めに見積もり、10ページ以上になると直近10ページのPNGの平均で見積もります。

足りないときは「RAW保存に必要な空き容量が不足しています。」と表示して作業フォルダーを中断状態にします。空きを作ってから、「⑤ 保存済み作業フォルダを開く」で再開してください（[12章](12-resume.md)）。

## 取得範囲は自動で決まります

ADB直接取得では、AVD内部の画面全体を取得します。Windowsの表示倍率やウィンドウの位置・大きさには左右されません。

GUIでは、マウスでキャプチャ範囲を選んだり、座標を入力したりしません。

> 💡 「出力・画質」タブの「出力用切り出し」にあるX,Y,幅,高さは、取得済みのRAWを書き出すときの画像処理の設定です。キャプチャ範囲の指定ではありません（[10章](10-export.md)）。

## 取得中のウィンドウの動き

ページを取得している間も、ebook2xtcのウィンドウは表示されたままです。AVDのウィンドウを前面に出したり、最前面に固定したりはしません。画像はADBでAndroidの画面から直接取得するため、AVDのウィンドウが他のウィンドウの裏に隠れていても、最小化されていても取得は続きます。取得中は、AVDの画面を操作しないでください。
