# 14. よくある質問・困ったとき

まず、左下のステータスと、「取得」タブの「事前準備」の枠に表示されたメッセージを読んでください。多くの場合、次に行うことが書かれています。

## 起動と配布

| 状況・表示 | 確認すること |
|---|---|
| `start_ebook2xtc.bat` から起動できない | バッチと `ebook2xtc.exe` が同じフォルダーにあるか確認します。`_internal` フォルダーも必要です（[1章](01-getting-started.md)） |
| WindowsのSmartScreenが警告する | バッチは同じフォルダーのEXEを起動するだけで、SmartScreenの警告を解除しません。配布元とファイルを確認し、実行を許可できる場合にだけWindowsの案内に従ってください。管理対象のPCでは管理者に確認します |

## AVDとAndroid

| 状況・表示 | 確認すること |
|---|---|
| アプリを起動してもAVDが起動しない | 仕様です。⓪〜②を選び、③でAVDを選んで「起動」を押します（[5章](05-launch-avd.md)） |
| 「Android Emulatorが見つかりません。」／AVDが一覧に出ない | SDK ManagerでAndroid EmulatorとPlatform-Toolsを入れたか、SDKの場所に `emulator\emulator.exe` と `platform-tools\adb.exe` があるかを確認します。環境変数を変えた場合は、アプリを起動し直します（[2章](02-android-studio.md)） |
| Device Managerなどで「Google generic no longer exists as a device」と表示される | 過去版のebook2xtcが付けた端末名が原因の場合があります。ebook2xtcの③で対象AVDを選び「起動」を押すと、無効な端末名を修復します。AVDが起動中の場合は、設定を反映するため再起動されることがあります。リーダーアプリのログインや書籍データは削除しません |
| 外部で起動したAVDが「Android AVD」欄に出ない | 「事前準備」の枠の③の下にある「AVD更新」を押します |
| 「…の起動を確認できませんでした。」 | 約3分待っても起動を確認できませんでした。AVDのウィンドウでAndroidが起動しているか確認し、「AVD更新」を押します |
| 「このPCではAVDの実行に使う仮想化を現在利用できません」 | 「準備を再確認」で再起動が後で必要になる確認画面が出ます。**OK** ならAVD作成を続け、キャンセルならセットアップを保留します。AVDを起動する前に「Windowsの機能を開く」から「Windows ハイパーバイザー プラットフォーム」を有効にし、**Windows PC本体を一度再起動**します。警告がなければ再起動は不要です（[2章](02-android-studio.md)） |
| 「…のEmulatorが起動直後に終了しました（終了コード …）。」 | Android StudioのDevice Managerから同じAVDを起動して、エラーを確認します。PCのメモリや仮想化の設定が原因のことがあります |
| ADBサーバーを起動できない | アプリは、設定済みのAndroid SDKの `adb.exe` を優先し、応答しないADBサーバーを再起動します。Windowsが既定のポート5037での待ち受けを拒否した場合は、5038〜5043も順に試し、成功したポートをAVDにも引き継ぎます。すべて失敗する場合は、エラーに表示されたADBのパスとポートの診断を確認し、Android Studioなど別のSDKを使うソフトを終了して「AVD更新」をやり直します |
| System Imageを入れたのに「標準環境をセットアップ」が押せない | 「準備を再確認」を押し、表示されたSDKの場所とAndroid Studioの **Android SDK Location** を比較します。必要なのはAndroid 15／Google Play／x86_64のイメージです。Google APIs版、Tablet版、16 KB版は別物です。SDKの場所が違う場合は「SDK保存先を指定（認識しない場合）」を押します（[2章](02-android-studio.md)） |
| Playストアがない | AVDのシステムイメージがGoogle Play対応か確認します。Google APIsだけのイメージには、Playストアが含まれないことがあります（[2章](02-android-studio.md)） |
| Androidまたはリーダーアプリが英語 | Androidの「System languages」で日本語を一番上にし、Android 13以降ではリーダーアプリの「App languages」も確認して、リーダーアプリを再起動します。リーダーアプリのアカウント地域は別の設定です（[3章](03-japanese-and-reader.md)） |
| ログイン欄に入力できない | AVDの「Enable Keyboard Input」を有効にし、AVDのウィンドウを前面にして入力欄をクリックしてから、PCのキーボードで入力します（[4章](04-keyboard-and-sleep.md)） |
| リーダーアプリのID欄でかな入力から切り替えられない | AVD内のGboardならスペースキーを長押しして英語キーボードを選びます。PC側の日本語IMEならタスクバーの「あ」を「A」にするか、Windowsキー＋Spaceで「ENG」を選びます。詳しい手順は[4章](04-keyboard-and-sleep.md)を参照してください |
| 取得中にAVDの画面が消える | Developer optionsの「Stay awake」、AVDの充電状態、Windows PCのスリープ設定を確認します（[4章](04-keyboard-and-sleep.md)） |
| 取得する画面の解像度が合わない | 起動前に⓪と②を選び、アプリの「起動」からAVDを立ち上げ直します。寸法が違えば、アプリがAVDを再起動して合わせます。AVDのウィンドウの見た目の大きさは関係ありません（[5章](05-launch-avd.md)） |

## キャプチャ

| 状況・表示 | 確認すること |
|---|---|
| 連続取得中、ページごとに止まる時間が違う | 仕様です。ページごとに、最短待機 a〜最大待機 b（初期値0.5〜3.0秒）の範囲から待ち時間を無作為に選び、その時間がたってから保存します。選んだ値は作業フォルダーの `session.json` に `T_seconds` として残ります。間隔をそろえたい場合は、aをbに近づけます（その分遅くなります）。bは「ページ変化なし」と判定するまでの制限時間も兼ねるので、速くするためにbを下げるのはおすすめしません（[8章](08-stability.md)） |
| 「④ 新規作業フォルダを作成」が押せない | ③で「起動」を押して、取得画面を設定していません。案内に「次の操作：③で対象AVDを選び「起動」を押して取得画面を設定してください。」と出ます |
| 「⑥ リーダーアプリを開く（書籍選択・文字調整）」が押せない | ページを保存済みの作業フォルダーでは押せません。続きは「保存済みページの続きから連続取得」を使います |
| 「リーダーアプリを開けません」 | リーダーアプリがインストールされているか、AVDの寸法が選んだ値と一致しているかを確認します |
| ⑨が押せない | ⑦で表紙のプレビューを取得していません。⑦を押し、確認で「はい」を選びます |
| 「ページ変化がないためRAWは保存せず、…」 | 自動で再確認とページ送りのやり直しを行います。キーを送った後の変化なしが3回に達すると巻末候補として止まります。巻末でなければ、リーダーアプリの画面を確認して「保存済みページの続きから連続取得」で再開します（[8章](08-stability.md)） |
| 「最大待機時間内に画面が安定しなかったため、…」 | ページ描画やアニメーションが、最大待機時間内に落ち着いていません。bを少し長くするか、微細なちらつきだけが原因ならεを少し大きくします（[8章](08-stability.md)） |
| 「取得領域の中央がほぼ全黒です。…」 | 画面保護、または表示の異常の可能性があります。本当に黒いページだと確認できたときだけ、「全黒ページも許容（次の1ページだけ）」をオンにして続きから取得します（[8章](08-stability.md)） |
| 「直前ページとの完全重複を検出し、後のページ（…）を削除しました。」 | 巻末で同じ画面を2回取得したときの動きです。本の途中で出た場合は、ページ送りが効いていないので、リーダーアプリの画面を確認して続きから取得します（[7章](07-capture.md)） |
| 「重複候補」「交互ループ候補」で止まった | RAWはすべて保持しています。一覧の ⚠ の付いたページを見比べ、リーダーアプリの表示位置を直してから続きを取得します |
| 「空き容量不足のためセッションを停止しました。」 | 保存先のドライブの空きを作り、「⑤ 保存済み作業フォルダを開く」で再開します（[6章](06-before-capture.md)） |
| 「…ではページが変わりませんでした。次は「…」でページ送りを試します。」 | KindleとKobo以外のアプリで、ページ送りの方法を自動で判定している途中です。そのままお待ちください（[3章](03-japanese-and-reader.md)） |
| 「キー・画面端タップ・スワイプのどれでもページが変わらなかったため、…」 | リーダーアプリで本のページが表示されているか確認し、「その他」タブの「ページ送りの方法」で方法を選んでから再開します |
| 「ページ送りの方法を試したところ、ページではなくメニューなどが表示されたようです。」 | リーダーアプリのメニューを閉じ、最後に保存したページを表示してから再開します。次の方法で試します |
| `Esc` キーで止まらない | ebook2xtcのウィンドウをクリックして選んでから押すか、「停止（Esc）」ボタンを押します。AVDのウィンドウを選んだまま押すと、Androidの「戻る」になります（[7章](07-capture.md)） |
| 「このセッションは旧版のWindows画面取得で作成されたため、続きの取得はできません。」 | Windows画面取得は廃止しました。書き出しはできます。続きは、新しい作業フォルダーで取得し直します（[12章](12-resume.md)） |

## 再開・出力

| 状況・表示 | 確認すること |
|---|---|
| 「セッションを再開できません」 | 親フォルダーではなく、`ebook2xtc_…` または旧版の `s4capture_…` の作業フォルダーを選んだか確認します。RAWを手で動かした場合は、元に戻します（[12章](12-resume.md)） |
| 「中間PNGは削除済みです」 | その作業フォルダーは、出力後にRAWを消去しています。再開・再出力はできません（[11章](11-raw-cleanup.md)） |
| 「○ページ目のRAWまたは取得記録がありません。」 | `raw` フォルダーの画像か `.capture.json` を、エクスプローラーで削除または移動していないか確かめます。消したファイルを元の場所に戻すと開けます。最後の不要なページは、ファイルを消さずに「このページ以降を取り除く」で出力から外します（[10章](10-export.md)） |
| 本の最後に不要な画面（レビューの依頼など）が入った | 右ペインでその画面を表示し、「このページ以降を取り除く」を押します（[10章](10-export.md)） |
| 「選択形式を書き出す」が押せない | ページを1枚も保存していない、取得中または連続取得中、⑥〜⑦の準備中、書き出しの最中、のいずれかです。中間PNGを消去済みの作業フォルダーでも書き出せません |
| 「対応外のRAW寸法です」 | ⓪出力対象が、取得したときの機種と同じか確認します（[10章](10-export.md)） |
| 「出力記録を保存できません」 | 書き出しは完了していますが、台帳に記録できませんでした。RAWを消去しないでください。作業フォルダーの書き込み権限と空き容量を確認します |
| 変換が止まる・失敗する | 元のRAWとセッション台帳を残し、空き容量・保存先・表示されたエラーを確認します。途中まで書かれたファイルを、手作業で完成扱いにしないでください |
| 文字が読みにくい | 同じRAWから、余白、文字太らせ、しきい値、ディザ、XTC／XTCHを1つずつ変えてプレビューし、候補を比べます。最終的な判断は実機の表示で行います（[10章](10-export.md)） |
| 「環境プロファイルの読み込みは、キャプチャセッションと変換を終了してから行ってください。」 | 連続取得を停止して「キャプチャを終了」を押すか、変換が終わるのを待ってから読み込みます。アプリの再起動は不要です（[13章](13-migration.md)） |
