# 10. プレビューとXTC／XTCH出力

取得したRAWは、「出力・画質」タブでXTC（2階調）やXTCH（4階調）に書き出します。書き出す前に、右ペインで仕上がりを確認できます。RAWは書き出しで上書きされないので、設定を変えて何度でも書き出せます。

既定では、1ページ目から作る一覧用のサムネイルを埋め込みます。意図した表紙が1ページ目にあることを、書き出す前に確認してください。

## プレビューで確認する

右ペインの取得ページの一覧、またはプレビューの下の「◀ 前ページ」「次ページ ▶」とページ番号の欄で、表示するページを移動します。上部の欄で、プレビューの種類を選びます。

この「◀ 前ページ」「次ページ ▶」は、保存済みのページを表示するだけで、AVDのページは送りません。AVDへページを送るのは、「取得」タブの⑥の欄にある同じ名前のボタンです（[7章](07-capture.md)）。

| 種類 | 使いどころ |
|---|---|
| RAW | 取得した画像そのもの。ページ順や、通知が写り込んでいないかの確認 |
| XTC 2階調プレビュー | 白黒2階調にしたときの文字のつぶれ・かすれの確認 |
| XTCH 4階調プレビュー | 4階調にしたときの挿絵や薄い文字の確認 |
| 余白・切り出しプレビュー | 余白削減や出力用切り出しで、どこまで残るかの確認 |

出力の設定を変えると、選択中のページのプレビューがすぐに更新されます。プレビューと書き出しは、同じ処理と同じ値を使います。

## 形式・画質・画像処理

「形式・画質・画像処理」の枠の項目です。

| 項目 | 選択肢・初期値 | 説明 |
|---|---|---|
| 形式 | XTC (2階調)／XTCH (4階調)／XTCとXTCH（2形式を同時に出力） | 書き出す形式です。「XTCとXTCH」では、同じ処理条件でXTCとXTCHを続けて書き出します |
| 出力サイズ | 標準（X4は480×800、X3は528×792。初期値）／Comic（X4は960×1600、X3は1056×1584。SROS専用） | Comicは、カスタムファームウェアSimple Reader OS（SROS）のComic Readerで読むための、端末画面の縦横2倍のページです。下の「Comicサイズで書き出す」を参照してください |
| XTC圧縮 | 非圧縮のみ（初期値）／LZ4圧縮のみ（`*_comp.xtc`／`*_comp.xtch`）／非圧縮とLZ4圧縮を両方出力 | LZ4圧縮版は対応ファームウェアが必要です。出力サイズがComicのときは圧縮方式が決まっているため、この欄は表示しません |
| 画質プリセット | 手動設定／文字優先／バランス／挿絵優先 | 下の「画質プリセット」を参照してください |
| しきい値 | 0〜255（初期値128） | 明るさの境目です。上げるほど黒く（濃く）なる画素が増えます。XTCではディザがオフのときだけ使い、XTCHでは4階調に分ける境目の基準になります |
| 余白 | オリジナル／余白削減 1／余白削減 2 | 余白削減を選んでも、表紙（1ページ目）はオリジナルの余白を保ち、2ページ目から削減します。「出力用切り出し」を入力すると選べなくなります |
| 文字太らせ | オフ（初期値）／オン | オンにすると太さ5が選ばれます。オフでは太さのチェックボックスは操作できず、文字太らせを適用しません |
| 太さ（複数選択可） | 1〜8のチェックボックス（1が最も弱く、8が最も強い） | 1つ選ぶとその太さで通常出力します。2つ以上選ぶと太さごとに比較出力します。右ペインのプレビューは、選択中の最小の太さを表示します |
| 細い線の保護 | オフ／弱（初期値）／標準 | ディザをオフにしたXTCで、欠けた横線や薄い横棒を補います。文字太らせ5以上を想定しています。XTCHとディザがオンのXTCには適用しません |
| 出力用切り出し | 任意：`X,Y,幅,高さ`（例 `0,0,960,1600`） | 全ページ共通で、RAWの座標で切り出します。入力すると「余白」より優先されます |
| ディザを有効にする | オン（初期値） | 中間の明るさを点の密度で表します。挿絵の階調が残る一方、文字の周りに点が出ることがあります |
| 出力を反転する（黒背景・白文字） | オフ（初期値） | XTC／XTCHのページ画像を白黒反転して出力します。右ペインのXTC／XTCHプレビュー、埋め込みサムネイルにも反映します。RAW画像は変更しません |
| 表紙と挿絵をページの中央に置く | オン（初期値） | 楽天Koboなどは、表紙と挿絵を画面の上に寄せて表示します。オンのときは挿絵のページだけを見分けて、上下左右の中央に移します。挿絵とキャプションの位置関係はそのままです。本文・目次・扉のページは動かしません。背景が暗いページ（画面いっぱいの表紙など）も動かしません |
| サムネイルを埋め込む | オン（初期値） | 1ページ目から作る180×270の一覧用画像（XTG）を埋め込みます。LZ4圧縮版にも入ります。互換性を比べるときはオフにします。オフでもヘッダーは56バイト形式で、作業フォルダーの出力記録（`session.json`）にサムネイルなしと記録します。X4実機での一覧表示は未確認です |
| ページ番号 | オン（初期値）／オフ、大きさ6〜29 px（初期値12 px） | 各ページの右下に「ページ/総ページ数」（例 `301/945`）を入れます。下の「ページ番号と進捗バー」を参照してください |
| 進捗バー | オン（初期値）／オフ、位置：中央（初期値）／左寄せ | 各ページの下端に、本のどこまで読んだかを示すバーを入れます |
| 背景ノイズ抑制（白に近い画素を白固定） | オン（初期値） | XTCHでディザがオンのときだけ使えます。「XTCとXTCH」ではXTCHのファイルだけに適用します。明るさ245以上の画素を白に固定し、周りからのディザの誤差も遮断します |

画像は出力寸法へ一度だけ縮小します。縮小方式はlanczosに固定しています（実際の本のページで比べたところ、文字の形を最も正確に残したためです。bilinearでは横線が切れ、nearestでは線が消えることがありました）。余白削減や切り出しで拡大縮小が入るときは、輪郭を軽く補正してから階調化します。

表紙（1ページ目）は、余白削減1・2でも余白を削減しません。右ペインの余白・切り出しプレビューとXTC／XTCHプレビューにも、この扱いが反映されます。手動の「出力用切り出し」を指定した場合は、その切り出しを表紙にも適用します。

余白削減1・2は、本文の文字を切りません。出力前に全ページを調べて本文のある範囲を求め、削減すると本文にかかる場合は、その分だけ削減を控えます（全ページ同じ範囲を使うので、ページごとに文字の大きさが変わることはありません）。楽天Koboのように画面の端近くまで本文を表示するリーダーアプリでは、余白削減1・2を選んでもオリジナルに近い範囲になります。Kindleのページ上部の書名や下部の読書の進み具合のような灰色の表示は本文とみなさず、これまでどおり削減します。

> ⚠️ **文字太らせと背景ノイズ抑制の注意**: 文字太らせを強くすると、挿絵の暗い部分や、文字の細い隙間にも影響します。背景ノイズ抑制では、薄い文字や淡い挿絵が欠けることがあります。どちらも、プレビューで本文とルビを確認してから書き出してください。

「細い線の保護」は、ディザをオフにしたXTCで、文字太らせ後に2階調化すると消える薄い横線を補います。両端が黒い短い欠けと、周囲が明るく細い横棒を対象にします。白い文字間や孤立した点は補いません。「弱」は短い欠けと一定以上の長さの横棒、「標準」はもう少し広い範囲を対象にします。ルビの隙間がつながる場合があるため、右ペインのXTCプレビューでルビの多いページも確認してください。ディザをオンにしたXTCとXTCHには適用されません。

## ページごとのディザ設定

「ページごとにディザを自動判定」をオンにすると、取得したRAWごとに、写真・挿絵らしい濃淡が十分あるかを判定します。画像と判定したページはオン、文字中心や判断が難しいページはオフで出力します。ルビを含む文字が画像と誤判定されにくいよう、保守的な条件にしています。

右ペインはページの選択とプレビューに使います。ページを選んだら、「出力・画質」タブの「選択ページのディザ」で判定結果を確認し、必要なら「このページはディザ オン／オフ」に変更してください。「自動判定を使う」に戻すと自動判定に戻ります。選択ページの設定は自動判定がオンのときだけ使われ、作業フォルダーに保存されるため、作業再開後も引き継がれます。自動判定をオフにするとページ別設定欄は使えず、「ディザを有効にする」の設定が全ページに適用されます。

自動判定をオフにすると、従来どおり「ディザを有効にする」のオン・オフをすべてのページに使います。自動判定は元のRAWを対象とするため、線画や文字と画像が混在するページ、余白の切り出し後の内容では意図どおりにならないことがあります。XTC／XTCHプレビューで確認してから書き出してください。判定はページ単位であり、同じページ内の文字と絵を領域ごとに分けて処理する機能ではありません。

## 画質プリセット

画質プリセットは、比較を始めるための設定の組み合わせです。 アプリの「画質プリセット」横の「?」でも各設定を確認できます。**どれも実機では評価していません。** 選ぶと、次の値がまとめて設定されます。

| プリセット | 余白 | 文字太らせ | しきい値 | ディザ |
|---|---|---|---|---|
| 文字優先（試験設定・実機未評価） | 余白削減 1 | 5 | 128 | オフ |
| バランス（比較設定・実機未評価） | オリジナル | なし | 128 | オフ |
| 挿絵優先（試験設定・実機未評価） | オリジナル | なし | 128 | オン |

- プリセットを選んだ後に個別の値を変えると、表示が「手動設定」に戻ります。
- 書き出したときの出力記録（`session.json`）には、使ったプリセットのIDを記録します。
- 実機で良い結果が得られた設定を基準にして、必要なら個別の値を調整してください。

## ページ番号と進捗バー

「ページ番号」と「進捗バー」をオンにすると、日本語XTC GUI Studioと同じ表示を各ページの下端に入れます。どちらか一方だけでも使えます。初期値はどちらもオンです。前の版でオフにして保存した設定や、オフで書き出した作業フォルダーでは、オフのまま引き継ぎます。

- ページ番号は右下に「ページ/総ページ数」で入ります。進捗バーは、ページ番号と重ならないように置きます。
- 進捗バーは、取得タブの「本の読み方向」が「左から右」なら左から、それ以外（「右から左」「未指定」）なら右から伸びます。
- 表紙（1ページ目）には入れません。ページ番号は表紙を1ページ目として数えます。
- 取り込んだページには、ページ番号などのための余白がありません。そこで、オンのときはページ全体を少し縮め（標準サイズで高さ約2%）、下端に白い帯を空けてから描きます。本文や挿絵には重なりません。
- 大きさは、480×800のページでの文字の高さです。Comicでは2倍の大きさで描くので、端末に縮小表示したときに同じ大きさに見えます。
- 右ペインのXTC／XTCHプレビューにも反映します。

## Comicサイズで書き出す

「出力サイズ」でComicを選ぶと、端末画面の縦横2倍の大きさ（X4は960×1600、X3は1056×1584）でページを作ります。日本語XTC GUI StudioのX4 Comic／X3 Comicと同じ大きさと形式です。SROSのComic Readerは、画面に合わせて縮小して表示するので、小さい文字や図の細部が残ります。マンガだけでなく、図や小さな文字の多い技術書にも向いています。

- ② キャプチャ解像度を「高画質 2倍」にして取得したRAWが必要です。2倍のRAWは縮小せずにそのまま使います。原寸で取得したページがあると、書き出す前に理由を表示して止まります。
- XTCは、ページ単位でLZ4圧縮した `*_comp.xtc` だけを保存します。
- XTCHは、XTCH v2（4KBごとにLZ4圧縮した4階調の形式）の `*_comp_v2.xtch` だけを保存します。書き出した後で全ページを読み直し、元のXTCHと同じ内容に戻ることを確かめてから保存します。
- 「XTCとXTCH」では、`*_comp.xtc` と `*_comp_v2.xtch` の2ファイルを保存します。
- 余白削減・文字太らせ・ディザなどの画像処理は、標準サイズと同じように使えます。右ペインのXTC／XTCHプレビューも、Comicの大きさで表示します。
- 1ページの画素数が標準の4倍になるため、変換に時間がかかり、ファイルも大きくなります。開発環境での目安は、XTCが1ページ約0.2秒、XTCH v2が1ページ約0.5秒です。

> ⚠️ **ComicはSROS専用です**: Comicで書き出したファイルは、純正ファームウェアやCrossPointでは開けません。SROS以外で読む場合は、出力サイズを「標準」にしてください。

## 書籍情報と目次を書き込む

「書籍情報・目次」の枠では、XTC／XTCHに書き込む書籍情報と目次を設定します。日本語XTC GUI Studio v5と同じ形式で書き込むので、端末の書籍一覧や、目次から章へ移動する機能で使われます（使われ方はファームウェアによって異なります）。

| 項目 | 説明 |
|---|---|
| 書籍情報と目次をXTC／XTCHに書き込む | オン（初期値）にすると、取得タブ⑧の書名・作者・出版社と、開始ページを設定した章を書き込みます。オフにすると、これまでどおり書籍情報なしで書き出します |
| （要約） | 書き込む書名・作者・出版社と、章の数を表示します |
| 目次と章の開始ページ… | 章名と開始ページを確認・修正する画面を開きます。保存済みのページがあるとき（書き出し中を除く）に押せます |

### 章の開始ページを照合する

「目次と章の開始ページ…」の画面は、左に目次の章名と開始ページの一覧、右に保存済みのページ（RAW）のプレビューがあります。章名と開始ページは一覧で直接修正できます。

一覧の列：

| 列 | 説明 |
|---|---|
| 照合 | チェックした章を「チェックした章をKindleで照合」の対象にします。読み取った直後の章はチェック付き、「行を追加」で足した章はチェックなしです。開始ページを手で設定するとチェックが外れます |
| 章名 | ダブルクリックで修正できます。章名を空にした行は、「OK」で保存するときに一覧から除きます |
| 開始ページ | 保存済みのページの番号です。0（「未設定」）の章は書き込みません。数字を変えると、右のプレビューもそのページに移ります。マウスのホイールで数字が変わるのは、欄をクリックして入力中のときだけです（一覧をスクロールしても変わりません） |
| 結果 | 「照合済み」（照合で見つかった）、「見つからず」（照合で見つからなかった）、「手動」（手で入力した、またはプレビューから設定した）を表示します |

右のプレビューでは、ページを見ながら開始ページを決められます。

- 一覧で行を選ぶと、その章の開始ページを表示します。開始ページが「未設定」の章では、表示中のページのままにします（前の章の開始ページを入力して次の章へ移ったときも、ページは進みません）。ただし、表示中のページが前の章の開始ページより前のときは、前の章の開始ページの次のページへ移ります。
- 「◀ 前」「次 ▶」で1ページ、「≪ 10」「10 ≫」で10ページずつ移動します。ページ番号の欄に直接入力して移動することもできます。
- 「このページを開始ページにする」で、一覧で選択中の章の開始ページを、表示中のページにします（結果は「手動」）。設定すると、一覧の選択が次の章へ移るので、続けて次の章の開始ページを探せます（最後の章では選択はそのままです）。次の章の開始ページが未設定なら、プレビューは表示中のページのままです。
- プレビューの下に、表示中のページから始まる章を表示します。
- 中間PNGを消去した作業フォルダーでは、プレビューは表示されません。

一覧の下のボタンと、画面を閉じるボタン：

- 「Kindleから目次を読み取る」（楽天Koboでは「楽天Koboから目次を読み取る」）：リーダーアプリの目次から章名を読み取り、一覧を置き換えます（取得タブ⑧の読み取りと同じです）。一覧に章があるときは、置き換えてよいか確認します。入力済みの開始ページも消えます。章名を1つも読み取れなかったときは、一覧をそのまま残します。読み取った書名・作者は「OK」を押したときに⑧へ入ります。取得中は押せません。
- 「チェックした章をKindleで照合」（Kindleだけ）：「照合」欄にチェックした章を、Kindleの目次から1つずつ開き、表示されたページを保存済みのRAWと比べて開始ページを決めます。1章あたり8秒ほどかかります（50章で7分ほど）。照合できた章は「照合済み」、見つからなかった章は「見つからず」と表示します。見つからなかった章は、右のプレビューで探して開始ページを設定します。
- 照合し終えた章は、見つかったかどうかにかかわらず「照合」欄のチェックが外れます。開始ページを手で入力した章や「このページを開始ページにする」で設定した章も、チェックが外れます。このため、あとで照合しても手で設定した開始ページは上書きされません。照合し直したいときは、チェックを付け直します。照合の結果は、その場で作業フォルダーに保存します（画面を「キャンセル」で閉じても残ります）。
- 照合を途中で「中止」した場合や、途中で失敗した場合も、それまでに照合した章の結果は残ります。残りの章はチェックが付いたままなので、もう一度「チェックした章をKindleで照合」を押すと続きから照合します。画面を閉じたり、アプリを終了したりした後でも同じです。見つからなかった章を照合し直すときは、その章にチェックを付け直します。
- 楽天Koboでは照合できません。目次を読み取ったあと、右のプレビューでページを探して開始ページを設定します。
- 「行を追加」：一覧で選択中の行のすぐ下（未選択なら末尾）に「新しい章」を追加し、章名の入力を始めます。
- 「行を削除」：一覧で選択中の行を削除します。Shift／Ctrlを押しながら選ぶと、複数行をまとめて削除できます。
- 開始ページを手で入力したときや「このページを開始ページにする」を押したときは、その時点の一覧（章名の修正を含む）をすぐ作業フォルダーに保存します。照合したときも同じです。
- 「OK」：一覧を作業フォルダーに保存して閉じます。開始ページが「未設定」の章は書き込みません。
- 「キャンセル」：保存せずに閉じます。ただし、開始ページの入力・設定や照合のときに保存した内容は残ります。それより後の変更（章名の修正、行の追加・削除など）だけが取り消されます。

照合するときの注意：
- 取得したときと同じ文字サイズ・余白などの表示設定のまま行ってください。表示設定を変えると、ページの区切りが変わり、照合できません。取得が終わった直後に行うのが確実です。
- 照合のあと、Kindleの表示位置は最後に照合した章に移ります。照合を中止した場合や失敗した場合も、途中の章に移っていることがあります。どの場合も、照合の最後にKindleの目次とツールバーを閉じ、ページだけの表示に戻します。取得を再開するときは「再開位置を確認」で表示位置を確かめるので、移った先のページがそのまま続きとして保存されることはありません。再開する前に、Kindleで最後に保存したページまで戻してください（[12章](12-resume.md)）。
- 中間PNGを消去した作業フォルダーでは照合できません（章名と開始ページの修正はできます）。

書き込みのきまり：
- 同じページから始まる章が複数ある場合（「第4章」と「4-1」が同じページにあるなど）は、一覧で先にある1件だけを書き込みます。Studioと同じ扱いです。
- 各章は、次の章の前のページまでとします。最後の章は最終ページまでです。
- 書名は128バイト（日本語で約42文字）、作者は64バイト（約21文字）、出版社は32バイト（約10文字）、章名は80バイト（約26文字）までで、それより長い部分は切り捨てます。
- 1ページ目を表紙として記録します。
- LZ4圧縮版、XTCH v2（Comic）にも同じ内容を書き込みます。

## 書き出す

1. 「書き出し」の「選択形式を書き出す」を押します。
2. 保存先を選びます。既定の保存先は作業フォルダーで、ファイル名は「書名 - 作者」です（下の「ファイル名」）。「XTCとXTCH」ではXTCのファイル名を選び、XTCHは同じ名前で拡張子だけ変えて保存します。
3. 「出力内容の確認」で、次の内容を確かめます。

| 確認する項目 | 内容 |
|---|---|
| ページ数 | 書き出すページの数 |
| RAW解像度 | 取得したRAWの寸法（例：960×1600） |
| 出力形式 | 形式・機種・出力寸法、圧縮の有無 |
| 保存先 | 書き出すファイルの数と一覧。「XTCとXTCH」と「非圧縮とLZ4圧縮を両方出力」を組み合わせると、最大4ファイルです |
| 処理条件 | 余白／切り出し、文字太らせ（比較書き出しでは選んだ太さの一覧）、しきい値、ディザ、背景ノイズ抑制、反転モード、表紙と挿絵の中央配置、画質プリセット |

4. 画像に通知やアカウント情報が含まれていないかも確かめ、「はい」で書き出しを始めます。「キャンセル」を押すと書き出しません。
5. 書き出し中は、進捗バーに「全体進捗 N%」と、すべての段階を通した進み具合が表示されます。ステータスには「出力条件 1/1: ページを変換中（全体 12%）」のように、いまの段階と全体の割合が出ます。段階は、RAWの確認、ページのディザの判定（自動判定がオンのとき）、ページの変換、XTC索引の作成、ページデータの書き込み、LZ4圧縮の順に進みます。
6. やめるときは「変換をキャンセル」を押します。途中まで書き出したファイルは完成扱いにしません。「XTCとXTCH」でXTCHの途中にキャンセルまたは失敗した場合は、書き終えたXTCのファイルも削除し、何も出力しなかった状態に戻します。「XTCとXTCH」では、進捗の段階名に「XTC: 出力条件 1/2: …」のように形式名が付きます。
7. 終わると「出力完了」が開き、出力ファイルの場所が表示されます。
{: start="4"}

出力ファイルの横に処理記録（`.manifest.json`）は作りません。どのファイルをどの条件で作ったかは、作業フォルダーの `session.json` の出力記録に、ファイルごとに残ります（形式、LZ4圧縮の有無、文字太らせ、余白、縮小方式、しきい値、ディザ、背景ノイズ抑制、反転モード、表紙と挿絵の中央配置、画質プリセット、サムネイルの有無）。以前の版で作られた処理記録は、アプリからは削除しません。

> 📏 選んだ機種の原寸または2倍以外の寸法のRAWが含まれていると、「対応外のRAW寸法です」と表示して書き出しません。⓪出力対象が、取得したときの機種と同じか確かめてください。

## 文字太らせを比べる

文字太らせは、実機での読みやすさに大きく影響します。「文字太らせ」をオンにし、「太さ（複数選択可）」で太さを2つ以上選ぶと、1回の操作で太さごとに書き出せます。

1. 「出力・画質」タブの「文字太らせ」をオンにし、「太さ（複数選択可）」で比べたい太さにチェックを付けます（例：5、6、7）。書き出しボタンが「太さ3種類で書き出す」に変わります。
2. ボタンを押し、保存先を選びます。選ぶのは太さを付ける前の名前（例：`草枕 - 夏目漱石.xtc`）で、実際のファイル名には `_W5` のように太さが付きます。
3. 「出力内容の確認」で、作られるファイルの一覧を確かめてから「はい」を押します。
4. 書き出し中の進捗には「太らせ5 XTC: 出力条件 1/3: ページを変換中（全体 12%）」のように太さが表示されます。
5. 途中でキャンセルまたは失敗した場合は、書き終えた太さのファイルもすべて削除し、何も書き出さなかった状態に戻します。

- 太さを1つ選んだ場合は通常のファイル名で、その太さを適用します。複数選んだ場合は各ファイル名に `_W5` のような太さが付きます。太さ以外の値（余白・しきい値・ディザ）は、今の設定のまま使います。
- 文字太らせをオフにすると太さのチェックは外れ、選択もできなくなります。
- 書き出し時間は、選んだ数にほぼ比例して増えます（3種類で約3倍）。フォントテストで止めた10ページ程度の作業フォルダーで比べると、短い時間で済みます（[7章](07-capture.md)）。
- 右ペインのプレビューは、選択中の最小の太さで表示します。複数選んだ場合は、各太さの出力を実機で比較してください。
- チェックの状態は、次回の起動にも引き継がれます。

## ファイル名

「書名 - 作者」を共通のベース名にします。

| 出力 | ファイル名の例 |
|---|---|
| XTC | `草枕 - 夏目漱石.xtc` |
| XTCH | `草枕 - 夏目漱石.xtch` |
| LZ4圧縮のみ | `草枕 - 夏目漱石_comp.xtc`（XTCHなら `_comp.xtch`） |
| 両方 | `草枕 - 夏目漱石.xtc` と `草枕 - 夏目漱石_comp.xtc` |
| XTCとXTCH | `草枕 - 夏目漱石.xtc` と `草枕 - 夏目漱石.xtch` |
| XTCとXTCH＋両方 | `草枕 - 夏目漱石.xtc`、`草枕 - 夏目漱石_comp.xtc`、`草枕 - 夏目漱石.xtch`、`草枕 - 夏目漱石_comp.xtch`（4ファイル） |
| 文字太らせの比較（5・6・7） | `草枕 - 夏目漱石_W5.xtc`、`草枕 - 夏目漱石_W6.xtc`、`草枕 - 夏目漱石_W7.xtc` |
| 比較＋LZ4圧縮版 | `草枕 - 夏目漱石_W5_comp.xtc` のように、太さの後に `_comp` が付きます |
| Comic（XTC） | `草枕 - 夏目漱石_comp.xtc` |
| Comic（XTCH） | `草枕 - 夏目漱石_comp_v2.xtch` |
| Comic（XTCとXTCH） | `草枕 - 夏目漱石_comp.xtc` と `草枕 - 夏目漱石_comp_v2.xtch` |

- 書名だけ、作者だけの場合は、入力したほうだけを使います。どちらも空なら `output` になります。
- `\ / : * ? " < > |` などファイル名に使えない文字は `_` に置き換え、長さは120文字までにします。
- 同じ名前の出力がすでにある場合は、上書きせずに `草枕 - 夏目漱石(1).xtc`、`(2)` …のように番号を付けます。「両方」や「XTCとXTCH」では、どれか1つでもあれば、すべてに同じ番号を付けます。文字太らせの比較では、番号は太さの後に付きます（`草枕 - 夏目漱石_W5(1).xtc`）。
- XTC／XTCHコンテナのヘッダーは、LZ4圧縮版も含めて56バイト形式です。ページ索引は56バイト目から始まり、旧48バイト形式は完成品として保存しません。サムネイルをオフにしてもヘッダーは56バイトです。
- Studioと同じ方式で、圧縮効果のある本文ページの画像データだけをLZ4圧縮します。圧縮ページのヘッダーには圧縮フラグ1と圧縮後の長さを記録し、索引とサムネイル位置を更新します。サムネイルは圧縮しません。圧縮できるページが1枚もない場合、圧縮版は作成しません。「両方」では非圧縮版だけを保存し、完了時のステータスに「圧縮効果のあるページがないため、LZ4圧縮版は作成しませんでした」と表示します。
- 旧版の`.xtcz`は異なる形式で、拡張子を`.xtc`や`.xtch`に変えるだけでは読めません。保存済みのRAWから書き出し直してください。

> 📁 **旧版のファイルは自動で置き換わりません**: 48バイト形式のXTC／XTCHが残っている場合は、現行版で作業フォルダーのRAW画像から書き出し直し、「出力完了」に示された新しいファイルを実機へコピーしてください。同名ファイルがあれば `(1)` などの番号が付くため、古いファイルを選ばないよう注意してください。RAWを削除済みの場合は、書き出し直しの前に元画像の有無を確認してください。

> 📟 **LZ4圧縮版は対応ファームウェアが必要です**: 端末とファームウェアごとの互換性を確認してください。

## 実機で確認する

選択した機種で開き、本文・漢字・ルビ・余白・濃さ・ページ順を確認します。設定を比べるときは、処理条件を変えて書き出したファイルを実機で見比べてください。アプリは画質を自動では判定しません。

> 🧪 X3で開けることは、まだ実機で確認していません。X3で使う場合は、短い出力で開けるかを先に確かめてください。

書き出しに成功したら、中間PNGを残すか消すかを決めます（次章）。

キャプチャ中は書き出しを開始できず、書き出し中は追加のキャプチャを開始できません。RAWの消去を案内する前に、最後に書き出したページと現在のRAWページが一致するかを確認します。書き出し後にページを追加・変更した場合、RAWは保持されます。
